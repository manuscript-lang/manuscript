If the parent elects to pursue canonical discovery separately, the smallest additional proposal is workspaceSymbols-only generated CLOSED candidate grouping. CLOSED means no admitted actual ordinary open URI supplies that physical file's text; testing only `docs[generated.URI]` is insufficient. Every actual open URI remains independently appended with its exact text/version, including encoded variants and aliases. Private workspaceDocuments/references and all strict checked analyses remain unchanged.

Select nearest manifest from each original scope before canonicalization, including invalid manifests; record selection kind (manifest or standalone-directory) and effective recursive policy. Equivalent generated scopes could use `(canonical selected containing directory, effective recursive, kind)` and retain the first representative's lexical rebasing. No Program/result cache would be added. Before suppressing a generated file from a later representative, derive that file's nearest manifest from both rebased paths and canonicalize their containing directories; unequal/uncertain selected contexts must opt out rather than infer equal aliases from shared bytes. The per-file check could consume more filesystem work than the saved callbacks, strengthening do-nothing.

Any divergent admitted physical open text, decoded-URI ambiguity, directory canonicalization failure or CanonicalOverlay error would opt out to lexical assembly identity. Preserve actual URI records and existing suppression of generated ambiguous identities; never replace validation errors with empty overlays. The optout is not proven necessary beyond the approved existing ambiguity rule, so do not manufacture a tautological test to justify it.

Skeptical counterexamples: directory aliases with different lexical ancestor manifests; valid/invalid nested boundaries and aliases; symlinked manifest files under distinct containing directories; standalone symlink FILE confinement; unsaved open aliases whose generated URI differs; divergent encoded URI request overrides. Per-file selected identity must survive these without deduplicating actual documents. If a reviewer finds a counterexample or the additional checks erase the tiny benefit, withhold canonical discovery.

Acceptance would require full normalized symbol payloads, all requested text/locations, unchanged references, alias-order matrix, a strict-analysis counter proving flat CLOSED checks for1/2/4 aliases, plus ordinary no-alias controls. Old lexical assembly should fail the new work-count assertion; physical-only grouping must fail selected-context fixtures. Controlled wall/allocation measurements would follow correctness, never justify identity by timing alone. Root must explicitly authorize implementation after independent review; this document itself authorizes none.
