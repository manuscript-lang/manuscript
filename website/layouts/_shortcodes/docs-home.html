Manuscript

The language
for the agentic era.

A statically typed, natively compiled language with single ownership: no garbage collector and no lifetime annotations. Agents now write much of the code, so the compiler checks ownership, types and effects, and every diagnostic names its cause and fix. An agent can correct itself, and a person can review the result through built-in diagrams and an interactive code map.

Built for the agent loop

  • One owner per value. No GC, no lifetimes to write, and use-after-move is a compile error. Ownership rules
  • Failure is a value. T! and T? make errors and absence visible. There is no any and no reflection.
  • Effects the compiler checks. Declare one in a comment and ms lint flags every caller that did not allow it.
  • Diagrams and a code map. ms diagram builds an interactive, offline code map of types, calls and control flow, with a diff overlay for what changed. Code map {{ .Page.RenderString "![The code map's Calls tab: the callers and callees of a function beside its source, with the changed declarations listed on the left.](/images/code-map-calls.png \"The code map, Calls tab, with a diff overlay.\")" }}
  • Build speed. A 122,000-line project builds in debug in 5.4 s against 9.0 s for go build (measured 2026-11-05).
