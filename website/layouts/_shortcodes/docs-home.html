Why Manuscript

Designed for agents to write and humans to understand: familiar syntax, explicit ownership, scoped concurrency, and compiler feedback that helps repair mistakes.

  • Familiar syntax, native codefn, four-space blocks, fn x: x + 1 closures, 0..n and interpolated strings. Compile ahead of time through Cranelift or LLVM. Explore measured performance with the revision, machine and commands in the kernel results.
  • Feedback an agent can act onDiagnostics name the cause and remedy. ms check --fix applies available mechanical repairs; ms run --json reports faults with a kind, position and trace. Diagnostics.
  • Concurrency without asyncAny function can wait. TaskGroup, WorkerGroup and ProcessGroup own their work inside with and use typed channels. Choose a concurrency boundary.
  • Ownership you can followValues have one owner and deterministic drops; var marks mutation and .clone() marks copies. with scopes external resources. Ownership and borrowing.
  • A growing standard libraryFiles, processes, HTTP, JSON, data formats, command-line parsing and tests ship in ms. A batteries-included environment is the goal; discover the alpha library with ms search_symbol. Browse the APIs.
  • Measured against agentsThe benchmark records hidden-test results, first-build success and source size. The October 22 Manuscript run passed 10 of 10 small challenges; compile-fix rounds and source size still need work. Recorded agent results.
