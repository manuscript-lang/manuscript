Why Manuscript

The ambition is the ideal language for agentic development. Agent behavior, token use, human readability, and program analysis shape the design together.

  • Shaped by agent behaviorWe watch agents build programs, measure outcomes, tokens, and repair attempts, then use what we learn to improve syntax, APIs, and compiler feedback.
  • Make every token countA compact syntax, inferred types, and a small, regular core aim to use context efficiently while keeping intent clear to people and tools.
  • Keep reasoning localExplicit types at boundaries, visible mutation, and errors represented as values help agents make focused changes and people understand their effect.
  • Built to be analyzedStatic checking, source-based diagrams, and program inspection turn code into evidence that agents and reviewers can examine together.
  • Feedback that moves work forwardStructured diagnostics explain repairs. ms search_symbol finds exact APIs. ms verify brings type, formatting, lint, and test checks together.
  • Native code, measured performanceSource is checked, compiled to machine code, and linked with the runtime. Debug builds use Cranelift; optimized builds use LLVM when available. Benchmarks guide performance work. How compilation works.
