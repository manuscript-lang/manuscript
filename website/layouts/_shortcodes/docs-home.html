Built for the whole agent workflow

Give agents clear contracts, actionable feedback and a fast path from edit to execution. Keep the programs they produce efficient to run and easy to review.

  • Ownership without annotationsEvery value has one owner and borrows are the default, so there are no lifetimes to write and use-after-move is a compile error. Memory is freed deterministically when its owner ends, with no GC and no reference counts on values. .clone() is the only copy. Read the ownership rules.
  • Simple types that tools understandA small type system with generics and checked interfaces keeps types visible to the compiler. There is no any escape hatch or runtime reflection API. T! results and T? optionals make failure and absence explicit. Explore types and generics.
  • Effects the compiler checksDeclare an effect once and ms lint flags every caller that did not allow it, naming the call chain that brings it in. Effects are comments, so the language gains no extra syntax.
  • Turn feedback into the next editDiagnostics give agents a cause and suggested fix. ms check --fix applies supported repairs; ms verify gives the agent one command for type, formatting, lint and test checks. Failure is a value (T!), and Error is one pointer wide, so a fallible function uses no more stack than an infallible one. Meet the toolchain.
  • Iterate quickly. Ship optimized.Choose Debug builds for the agent’s edit–run loop, then optimized Release builds for production. Cranelift prioritizes compile speed; LLVM adds inlining and vectorization when available. A generated 122,000-line project builds in debug in 5.4 s against 9.0 s for go build (measured 2026-11-05). Choose a build mode.
  • Compose concurrent work without ceremonyAgents can start reads and requests together, then wait where results are needed. Promises run across all cores, provide timeouts and shared cancellation signals, and borrow their captures read-only, so the checker rules out data races. A parked promise costs about 5 KB on Linux and idle stacks hibernate, so millions fit in memory. See how tasks work.
  • Understand what your agent builtGenerate a self-contained HTML code map with ms diagram. Read source beside checked types, calls and control flow, then add a diff overlay to focus on changed declarations. Open the file offline and follow the program’s structure. Explore the code map.
  • Batteries-included standard libraryBuild with files, HTTP/1.1, HTTP/2, TLS, WebSocket, streams, processes, JSON, YAML, TOML, time, crypto and testing APIs bundled with ms. Typed JSON decodes straight into your types, with a decoder generated per type at compile time and no reflection; scope-end cleanup closes the resources your program owns. Build something useful.
  • Measure, then improveProperty tests double as a fuzzer with ms test --fuzz, ms bench times each change, and ms profile gives source attribution, pprof and folded stacks. An agent can run that loop on its own. Learn testing.

Built in Rust, with most of the standard library written in Manuscript. Shaped by recorded agent runs and reproducible performance tests.
