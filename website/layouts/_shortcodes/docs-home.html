Built for the whole agent workflow

Give agents clear contracts, actionable feedback and a fast path from edit to execution. Keep the programs they produce efficient to run and easy to review.

  • Simple types that tools understandA small type system with generics and checked interfaces keeps types visible to the compiler. There is no any escape hatch or runtime reflection API. Records and Result make data and outcomes explicit. Explore types and generics.
  • Turn feedback into the next editDiagnostics give agents a cause and suggested fix. ms check --fix applies supported repairs; ms verify gives the agent one command for type, formatting, lint and test checks. Meet the toolchain.
  • Iterate quickly. Ship optimized.Choose Debug builds for the agent’s edit–run loop, then optimized Release builds for production. Cranelift prioritizes compile speed; LLVM adds inlining and vectorization when available. Choose a build mode.
  • Compose concurrent work without ceremonyAgents can start reads and requests together, then wait where results are needed. Promises provide timeouts and shared cancellation signals without threading async and await through callers. See how tasks work.
  • Understand what your agent builtGenerate a self-contained HTML code map with ms diagram. Read source beside checked types, calls and control flow, then add a diff overlay to focus on changed declarations. Open the file offline and follow the program’s structure. Explore the code map.
  • Batteries-included standard libraryBuild with files, HTTP, streams, processes, JSON, time, crypto and testing APIs bundled with ms. Typed JSON reads records directly; scope-end cleanup closes the resources your program owns. Build something useful.

Built in Rust, with most of the standard library written in Manuscript. Shaped by recorded agent runs and reproducible performance tests. Alpha: syntax and APIs can change; this book follows the repository. Run your first program.
