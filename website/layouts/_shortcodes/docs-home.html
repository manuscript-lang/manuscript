Built for the whole agent workflow

From the first draft to the code you ship: catch mistakes, guide repairs, and keep the result easy to review.

  • Make intent explicitRecords describe your data; Result makes expected failures part of the type. Decode JSON into records with field types checked and defaults applied. See practical examples.
  • Give agents a repair pathDiagnostics explain the cause and fix. ms check --fix applies mechanical repairs; ms verify checks, formats, lints and tests in one command. Meet the toolchain.
  • Keep ordinary code nativeCompile to a native executable; run it without installing Manuscript on the destination machine. Static types and optimized release builds keep the path from source to machine code direct. Inspect reproducible benchmarks.
  • Run concurrent work, read straight throughStart reads and requests together, then wait where their results are needed. Promises support timeouts and shared cancellation signals without async or await. See how tasks work.
  • Review what a change meansms review --diff highlights changes to contracts, error flow and resource scopes. ms diagram makes calls and control flow visible. Explore semantic review.
  • Keep lifetimes clearOwned values are released deterministically, with inferred borrows and no lifetime annotations. Resources inside records and collections close when their owning scope ends. Follow the cleanup rules.
