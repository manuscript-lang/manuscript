# Guide

The guide teaches Manuscript through one small online shop. Each chapter adds a program that does real work and one idea you need to read it. Every program runs as shown.

1. [Values and functions](values-and-functions.md): totalling an invoice.
2. [Data](data.md): types, enums, lists, maps and sets for orders.
3. [When things go wrong](when-things-go-wrong.md): parsing order lines that might be wrong.
4. [Who owns what](ownership.md): moving and copying a cart.
5. [Cleaning up](cleaning-up.md): reading a file that always gets closed.
6. [Doing things at once](doing-things-at-once.md): reading several files together.
7. [Organizing code](organizing-code.md): interfaces and generics for a catalog.
8. [Testing and shipping](testing-and-shipping.md): tests, a property test, and a release build.
9. [Working with an agent](working-with-an-agent.md): the loop from first typo to reviewed change.

Run `ms` first if you have not: [Run your first program](../learn/getting-started.md). Each chapter ends with a link to the exact rules.
