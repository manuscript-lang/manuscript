# Core language

[Book index](../_index.md)

Learn to read and write Manuscript one step at a time. If you have not run a program yet, start with [your first program](../getting-started.md).

## Suggested reading order

| Step | Read | What you will be able to do |
| --- | --- | --- |
| 1 | [Language basics](basics/_index.md) | Read a file, name values with `let` or `var`, and use numbers and text. |
| 2 | [Functions](functions/_index.md) | Declare inputs and outputs and call functions with named arguments. |
| 3 | [Types and data modeling](types/_index.md) | Model data with records, alternatives, optional values, and collections. |
| 4 | [Control flow](control-flow/_index.md) | Choose a branch, repeat work, and handle each case of an alternative. |
| 5 | [Errors and validation](errors/_index.md) | Return expected errors, handle them, or forward them with `try`. |

You do not need to read every reference page before writing code. Return to [grammar](basics/grammar.md), [operators](basics/expressions.md), and [type compatibility](types/compatibility.md) when you need an exact rule. [Core conformance fixtures](../compiler/conformance/core-language.md) contain complete modules and their expected outcomes.
