# Control flow

Use `if` for a Boolean decision, `match` for alternatives, and loops for repeated work. Leaving a block runs its registered cleanup.

| Concept | What you will learn |
| --- | --- |
| [Conditionals](conditionals.md) | Branch on Bool values with if and else. |
| [Loops](loops.md) | Iterate with for and while, and use break and continue. |
| [Pattern matching](pattern-matching.md) | Handle alternatives exhaustively and bind their payloads. |
