# Authority and effects

[Guide index](../_index.md) · [Design index](../../_index.md)

A capability gives a function access to an external service. An effect describes what the function can do through that access, including through other functions it calls. Read authority first, then the rules for inferred effect summaries.

- [Host services and capability values](authority.md) — Import standard host services or pass service values to helpers.
- [Inferred effects and call relationships](effects.md) — Follow external behavior through a function and the functions it calls.
