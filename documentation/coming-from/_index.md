# Coming from another language

These pages map habits you already have onto Manuscript. Each one answers the same questions in the same order: how do I handle errors, represent absent values, share data, and ship a program? The rest of the documentation never assumes you know another language, so you can skip these pages and lose nothing.

- [Coming from TypeScript](typescript.md)
- [Coming from Go](go.md)
- [Coming from Python](python.md)

Start with [Run your first program](../learn/getting-started.md) if you have not run `ms` yet.
