# Library recipes

Use the bundled library to turn input into useful output. These lessons build on the [language tour](../learn/tour.md): each develops a complete program, explains the library's data model, and explores what happens when input changes.

Start with [task recipes](../learn/common-tasks.md) for small programs that read arguments and files, process lines, or fetch HTTP responses. Then work through:

1. [Read and validate JSON](json.md): turn a configuration file into typed data, choose how to handle missing and unknown fields, and inspect documents whose shape varies.
2. [Render a text or HTML template](templates.md): separate presentation from data, repeat a section, handle missing values, and escape HTML output.

The [API reference](../standard-library/reference/_index.md) defines individual operations. These recipes show how to combine them. All files below belong in your own working directory; no changes to the installed standard library are needed.
