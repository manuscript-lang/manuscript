# The C lowering of a whole program sets its entry

- `ms_lower_program` (`compiler/src/check/lower_func.c`) lowers the entry module first, then what it imports, then the standard modules. Each module is a view (`LbView`); a body is lowered with its own module's view entered.
- The entry is the lowered `main` of the entry module (`lb_entry_main`). A `main` that returns `Int` is exported and is the entry. Any other gets the wrapper `main.1` (`compiler/src/check/lower_entry.c`), written as the Rust lowering writes it: exit 0 after `Void`; for a `Result`, print `error: MESSAGE` on standard error and exit 1, else exit with the `Int?` payload or 0. A caller must not set `MirModule.entry` itself.
- `ms_lower_module` (one module, for `lower-diff.sh`) sets no entry.
- A `Void!` function that ends without a `return` returns `ok(void)` (`lb_return_void`). A function that ends without returning for any other result is reported as `falls off the end` in the why report, so no function disappears without a line.
- A lowering refusal goes through `LB_UNSUPPORTED(lb)`, never a bare `lb->ok = false`: the why report then names the site. A helper that returns `false` is turned into `LB_UNSUPPORTED` by its caller, and `lc_check` runs before the why line is written.
- In the why census most `lower_body.c` call-site lines (callee has no lowered function) and most `ownership_walk.c` callee lines are cascades. Count roots: the first refusal of a function whose callees all lowered.
- A module constant is a function of no parameters; a use calls it and owns the result when the type owns memory (`lb_constant_use`, `lower_closure.c`). A constant that is a non-empty list literal of scalar constants is read as `list.const.view N` from the module's `consts` table, one table per use as in Rust; the diff scripts compare a view by its table's contents, not its number.
- Inside a constant no statement sets positions: each expression sets its own on entry and it stays (`lb_at_expression`); an operator sets it again after its operands.
- A join's temporary operands are held to the statement end (`lb_hold_temp`), newest dropped first; a `return` hands them to its scope exit.
- In a whole program the standard modules are loaded, so a native method (`fn List[T].length() Int: ...`) has a method row with a declaration but no body. `lm_has` is false for it and the call goes to its runtime function (`lb_native_method`); before, every `xs.length()` in a program was refused for want of a lowered function.
- The ownership walk follows a native method (`: ...`) without walking it: it takes only the parameters its signature marks `move`, and its result is a value of its own unless the declaration carries `// ms: borrows` (`List.get`, `Map.get`, `Map.keys`, `Map.values`, `List.slice`, `Optional.get`, `Result.get`, `Bytes.view`: the list in Rust's `native_borrow.rs`). A new native whose result points into its receiver needs the marker.
- A native method with no runtime function is instructions (`ln_method_without_function`): `is_some`, `is_none` and `get_or` of an Optional (`lower_optional.c`; the default is evaluated before the test and lowered without its `some` wrap, the unused owned operand is dropped in each branch), `clone` (`clone 1`), and for Bytes the list operation of the same name when its row is `@op=` or `@seq=` over the list alone (`lb_bytes_instruction`). A scalar out parameter takes no argument (`ln_argument_kinds`). `get` and `get_or` of a list or Bytes are `list.get`, with the range test and a join for a default (`lst_read_method`, before the runtime row is looked up); a temporary list is held to the statement end.
- Widening what the walk accepts sends new functions to the lowering: run the census under the sanitizer build (`target/cmake/test`) and `lower-diff.sh` after any such change. This one exposed a crash in `lf_element`, a signed overflow on `-9223372036854775808` and a native with a found flag and a text out parameter lowered as a plain call.
- `lower-program-diff.sh` compares by file name, including the file of a `scope` line (the frame of a default argument). C numbers files by module order and Rust by first reference; the numbers are not worth matching.
- Several threads fixed the same hello-world gaps at once (defaults, generic `print`, std import cycles). Fetch `main` and read the last hour of merges before starting a checker or lowering gap.
