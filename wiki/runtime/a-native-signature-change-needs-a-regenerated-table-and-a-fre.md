# A native signature change needs a regenerated table and a fresh runtime archive

Verified: lowering marshals native calls from `crates/ms-lower/rt_symbols.txt` (generated by `ms run tools/ms/symbols.ms`), not from the Rust source, and programs link `target/ms-native/libms_native.a`. Adding parameters to `msstd_process_command_spawn` without regenerating its table entry (it was a hand-written catalogue then) made compiled calls pass the out pointer as a mode and segfault inside the native; a stale archive instead ignored the new arguments. Crate tests that call the native directly passed both times.

A default that an implementation inherits from a bundled interface must be one `literal_default` understands (literals, `none`, `[]`, `Map[K, V]()`, `Bytes`, payload-free cases); anything else fails lowering with "missing argument" in programs that implement the interface (`Commands` fakes). A map parameter reaches the native as two lists through `split_map_argument`.

The table spells types as `type_name` shows them with paths dropped (`*const ObjCell<NetH>`), and lowering tests a few spellings by name (`*const ObjCell<`, `*mut Handle<`, `*const Timestamp`, `*mut InfoOut`, `...Wire`, `*const u8`); renaming such a type changes marshalling, so grep `rtcall.rs` and `natiface.rs` first.

Payload-free alternatives occupy one `i64` case index even inside a list ([layout](../../crates/ms-mir/src/layout.rs)). A bulk native can borrow that list directly: converting every alignment to an integer first would allocate before the table formatter checks its budgets. Keep the declared element type and verify every case in a [compiled call](../../tests/conformance/fixtures/e2e/stdlib/table.ms).

The public `format(rows, ...)` borrows the caller's matrix directly. A single-field owner adds no invariant or reusable state; the compiled fixture formats the same rows twice and then reads and mutates them without cloning the matrix.

When seeding a target directory from another checkout, cached artifacts can be
newer than this checkout's earlier source edits. Refresh changed-source mtimes
or clean the affected package before rebuilding, confirm the changed crate
actually compiles, and probe the new behavior through the resulting archive.
A successful Cargo exit alone does not prove a copied cache is current.

Example of the `err: ErrSlot` role in `ms-rt` itself: `msrt_string_slice`, `msrt_string_repeat` and `msrt_list_slice` store the failing values (`slice(2, 10) of a string with 5 bytes`) there, and lowering appends them after the status words (`string: value out of range: ...`). The native must initialize the slot (`string::init_err`) on every path, since lowering may read it for any failure status.

Apply when: changing the parameters of any `ms-std-*` or `ms-rt` export.
Evidence: [table](../../crates/ms-lower/rt_symbols.txt), [Stdio default](../../crates/ms-lower/src/call.rs), [called source check](../../tests/conformance/fixtures/e2e/stdlib/host.ms).
Verify: run `ms run tools/ms/symbols.ms`, `make runtime` and rebuild `ms-cli`, then run a compiled program that calls the native, not only crate tests; `runtime_symbol_catalogue_matches_archive` checks names, not parameters.
