# `extern fn` binds native symbols; planned natives stay labeled

Decision: `extern fn name(...) T` declares a bodiless function whose symbol is its Manuscript name, linked with `--link` (#1136, #1138). It may be exported; it cannot be generic, take defaults or `var` parameters, or be a method. Wrap an extern in an ordinary function to rename it. User externs follow `ms_abi.h` v1: sized numbers at their C width, `Bool`, `String`, `Bytes`, `List` of those, user `extern type` handles made by `ms_object_new`, and `Result` whose error cases carry nothing, `code: Int` or `message: String`. Every output is pre-filled with an empty value and dropped after the call, so a shim that skips or mis-writes one causes no undefined drop; a NULL object or an unknown status faults. A function argument (at most six parameters of those types but lists; an extern-type result is rejected) crosses as an `ms_fn` that the shim calls with `ms_call` on the same thread, and may keep with `ms_fn_retain`; so a closure passed to a user extern owns its captures, like the callbacks of `KEPT_CALLBACKS` natives. A fault inside the callback ends the program like `ms_fault`. `ms_on_stop` hooks run from the stop handler so a blocked shim can return. Calls from other threads, blocking work, sockets and per-isolate state are still unshipped stage 2 items of [foreign functions](../../proposals/foreign-functions.md), held while concurrency is under review. Planned and not shipped: `Weak[T]`, `Arena[T]` (#1133 marks them planned in the docs).


Apply when: adding natives or user-facing FFI; do not document planned items as available.
Evidence: [native functions](../../documentation/core-language/functions/native-functions.md), [ABI round trip](../../crates/ms-cli/tests/extern_link.rs).
Verify: `cargo test -p ms-cli --test extern_link` round-trips every signature type and callback on both backends, and a stop hook ends a blocked shim with 130; a generic or method extern is rejected.
