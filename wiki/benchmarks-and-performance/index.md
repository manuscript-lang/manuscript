# Benchmarks and performance

Perf and agent benchmarks, profiling.

- [Sorting records that own data uses the generated sort over bitwise scratch](sorting-owning-records-uses-bitwise-scratch.md): inlined comparator for `String`-holding records, 225M to 102M instructions, then 82M with the driftsort; scratch owns nothing so a comparator fault is safe.
- [User `hash()` values are mixed before they index a table](user-hash-values-are-mixed-before-indexing.md): identity-like hashes of small-int records clustered under linear probing (562 to 103 ms for 1M `Set[Pt]` operations).
- [Runtime fast paths are generated MIR with a runtime twin](runtime-fast-paths-are-generated-mir-with-a-runtime-twin.md): `ms-rt-hot` is deleted; map probes, `String.view` and `StringBuilder.append` inline through shared MIR in both backends; hash and probe change together; `update` passes a map address.
- [Numeric parsing needs invalid-input performance controls](numeric-parsing-needs-invalid-input-performance-controls.md): valid-input gains can hide overflow and malformed-input regressions; preserve error precedence and equivalent Rust validation.

- [`var` record parameters stay in the caller's slot](var-record-parameters-stay-in-the-callers-slot.md): wide-record methods no longer move every field out and back per call; `Bytes` reads inline (`Lines.next` 147 to 75 instructions per line).
- [Constant list tables iterated in a loop are built once](constant-list-tables-in-loops-are-built-once.md): `for d in [[1, 0], [-1, 0], ...]` inside a loop no longer allocates per pass (248 to 20 ms for 5M passes).
- [`map`/`filter` chains over numbers run as one loop](map-filter-chains-over-numbers-run-as-one-loop.md): filter/map/sum over reading lambdas build only the final result (163 to 78 ms on 2M elements).
- [Small literal maps are searched, not built](small-literal-maps-are-searched-not-built.md): lookups on a literal of up to 12 constants compare keys directly (85 to 4 ns per call).
- [A win needs a baseline comparison, not just a smaller number](a-win-needs-a-baseline-comparison-not-just-a-smaller-number.md): keep the raw hand-written baseline (the C controls in `bench/perf/kernels/c`) and distinguish logical work elimination from faster execution…
- [Benchmarks are a profiling guide, not a gate](benchmarks-are-a-profiling-guide-not-a-gate.md): results are only comparable on one machine and revision; record the commit and machine with the table, as the result files do.
- [A bounds check that stays in a heap loop is a lost range fact](a-bounds-check-that-stays-in-a-heap-loop-is-a-lost-range-fact.md): joined list origins, `shl`, widening to the type bound, and pruned `len - c` relations kept checks Rust does not have (heap 56.0M to 46.0M, Rust 47.1M).
- [A guard on `x + c` bounds `x`, so fixed-size blocks need no checks](a-guard-on-x-plus-c-bounds-x-so-fixed-blocks-need-no-checks.md): blocked byte scans in `.ms` vectorize once the range pass sees `i + j < len` (memchr 730 to 31 us); inventory of Rust perf fallbacks and the plan to remove them.

- [Consume library checksums and separate allocation phase from local cost](consume-library-checksums-and-separate-allocation-phase-from.md): a returned checksum that the harness discards is not evidence that the work stayed observable.

- [Empty Set relations need no membership probes](empty-set-relations-need-no-membership-probes.md): skip empty-right disjoint traversal while preserving callback behavior; keep nonempty and unrelated Map controls.
- [Benchmark drivers are `ms run` programs in the flat `bench/tools/` directory](benchmark-drivers-are-ms-programs-in-one-flat-directory.md): an entry file imports only below its own directory, so drivers share one `lib.ms` there; `make bench-check` tests them.
- [MIR pass tables use `ValueMap` except where cloned per block](mir-pass-tables-use-value-map-except-where-cloned-per-block.md): `ValueMap`/`ValueSet` cut MIR optimize by 12 to 14% instructions; `range` keeps a hash map because its environment is cloned per block.
- [Perf work follows data-oriented design and tries a faster design before a cache](perf-work-follows-data-oriented-design-and-removes-caches.md): flat arrays and indices over hash tables and pointers, structure of arrays, a cache only when measurement shows no faster design matches it.
- [Freed large blocks stay resident after an `/io` burst](freed-large-blocks-stay-resident-after-an-io-burst.md): 64 in-flight 2 MiB requests leave 111 MB resident; pinning glibc's mmap threshold fixes it but slows JSON parse ~20%.
- [Release LLVM builds split into parallel units](release-llvm-builds-split-into-parallel-units.md): one `opt`+`llc` per unit above 2 MiB of code; 350 s to 60 s at 122k lines, no cross-unit inlining; `MS_LLVM_UNITS` overrides.
- [The general suite covers many kinds of program, against Rust, Go and Node](the-general-suite-covers-programs-not-one-engineering-set.md): `bench/perf/suite/` replaces `engineering/`; first run found gaps in string `+=`, small promises, linked-list cursors and directory walks, not in compute.
- [Callgrind needs a smaller allocator reservation](callgrind-needs-a-smaller-allocator-reservation.md): the 256 GiB reservation fails under valgrind, so profiles show glibc `malloc` costs the real run never pays.
- [A temporary `stdout()` stream must not flush on close](a-temporary-stdout-stream-must-not-flush-on-close.md): per-write flush cost one syscall per output line and halved program speed through a pipe.
- [A returned `Map.get` is a borrow, not a copy](a-returned-map-get-is-a-borrow-not-a-copy.md): `JsonValue.get` stops deep-copying; callers that mutate the map need `.clone()`.
- [A read-modify-write is one API, not a syntactic pattern](a-read-modify-write-is-one-api-not-a-syntactic-pattern.md): `Map.update` is one lookup via the inlined word probe; the `get(k).get(d)` matcher was deleted (7.6 vs 10.1 vs 13.9 ms).
- [String fusion must not treat other-block drops as early](string-fusion-must-not-treat-other-block-drops-as-early.md): a leaf dropped on a sibling path is not dropped before the join; `Info::dropped_before` uses reachability, c36 -6.8% instructions.

- [URL parent resolution truncates existing prefixes](url-parent-resolution-truncates-existing-prefixes.md): avoid quadratic prefix copies while preserving root and slash semantics; measure ordinary relative-reference controls.
- [Deque rotation uses the shorter signed remainder](deque-rotation-uses-the-shorter-signed-remainder.md): normalize both directions without negating Int.min; retain partial-ring and unit-step controls.
- [Diff context windows need only new flags](diff-context-windows-need-only-new-flags.md): mark each Boolean once while preserving overlapping hunk windows and ordinary diff controls.
- [Image rotations preserve malformed shapes](image-rotations-preserve-malformed-shapes.md): copy valid pixels in one pass, preserve channel order and malformed-input behavior, and measure tiny-image controls without asymmetric dispatch.
- [A busy queue must not poll descriptors on every task switch](a-busy-queue-must-not-poll-descriptors-on-every-task-switch.md): poll every 32 switches; compare servers on one CPU by user and system time per request.
- [Fewer allocations need wall time, not just counts](fewer-allocations-need-wall-time-not-just-counts.md): a counted split cut allocations 22% and instructions 6% but cost 7% wall; inline short strings never allocate on clone.
- [Path resolution builders must preserve clean separators](path-resolution-builders-must-preserve-clean-separators.md): avoid growing-prefix copies without sending ordinary clean paths through dirty normalization; retain small/A/A and invalid-input controls.
- [CRC table input terms are independent of the register](crc-table-input-terms-are-independent-of-the-register.md): combine input-only terms before the rolling-state chain, verify native assembly and tiny/tail/seed controls.
- [Cranelift branches that pick a value need selects](cranelift-branches-that-pick-a-value-need-selects.md): emit `select` when both edges join one block; Cranelift never if-converts.
- [A Manuscript HTML parser matches Rust with Int tables and a flat tree](a-ms-html-parser-matches-rust-with-int-tables-and-a-flat-tree.md): atoms, Int `match` tables and a flat tree keep a Manuscript parser at Rust speed.
