# One spelling per operation; consolidate by domain

Decision: the stdlib reorganization (#659) removed duplicate routes: `cli` moved into `process` (`process.arguments`, `process.control().environment()` is the only environment API), the temp-root query moved to `FileSystem.temporary_root` (`fs` is the only temp-dir API), string-typed `crypto.hmac` was dropped for `HashAlgorithm.hmac`, and the SSE decoder became an interface with `feed`/`finish`/`retry` methods.

Round 2 (consolidation audit): `assert_*` aliases of `expect_*`, `chmod_link`/`chown_link`/`set_times_link` (now `follow_links Bool = true` like `stat`), `system.monotonic_time` (use `time.monotonic()`) were removed; `create_link`/`read_link`/`hard_link` became `create_symlink`/`read_symlink`/`create_hard_link`; `set_identity` takes `IdentityKind`, `endianness()` returns `Endianness`; `uuid_v4` moved next to the other UUIDs in `@std/data/uuid.ms`; `Version.compare`/`Version.format` are methods. Base64 has one `base64_encode`/`base64_decode` pair with `url_safe:` and `padded:` (the `_unpadded` pair is gone). A record method named `to_string` is shadowed by the intrinsic `to_string`, so name it `format`. `net.request`/`HttpClient.request` take a `Writable` body (the `request_bytes` pair is gone). Decision (Chinmay): keep both `5.seconds()` and `seconds(5)`; do not consolidate. Decision (Chinmay): `fetch` and `HttpClient` serve separate use cases and stay separate. Deferred: the three integer parsers, `sha256` helpers (the lowering special-cases them), `Int` bit operations as free functions.

Round 3 (hardening week): a type's text form is `to_string()`, never `format()`, `to_text()` or `text()`: `Version`, `BigRat`, `Complex`, `Address`, `Headers`, `HttpMethod`, `DnsKind`, `IpFamily`, `IpAddress` and `Cidr` use it; lowering honors an extern type's own `to_string` (it printed `[object]` before). `FetchResponse.text()` and `XmlNode.text()` stay because they read content, not convert a value. `Histogram.min()/max()` match every other `min`/`max`. `Instant.unshift` was dropped: `instant - duration` and `shift` of a negative duration cover it (the native stays for the operator). `Result.error()` (optional) was dropped: `is_error()` then `err()` is the one way to read a cause.

Round 4 (hardening week): a number type's constructor and parser are named for the type, as `rat_of_int` and `parse_rat` already were: `big_int_of_int` and `parse_big_int` replace the bare `from_int` and `parse`, which clashed when two number modules were imported. Header lookups read the same on both header types: `HttpHeaders.get` (first value) and `get_all`/`get_all_bytes` replace `values`/`values_bytes`, matching `Headers.get`/`get_all`. `Regex.find_span` returns a `RegexSpan?` like `find_all_spans`, and a decoder's `max_bytes` budget is its last parameter (`base64_decode`).

Regex capture methods are verb-first like the find family: `capture`, `capture_all`, `capture_named`, `capture_spans`, `capture_all_spans` (not `captures`, `captures_all`, `named_captures`). `JsonValue.get_index(index)` replaces `at`, which List lost in #669 (a type cannot overload `get` on key and index). `HttpHeaders.remove` returns nothing like every other `remove`; an absent name is a no-op.

Apply when: adding or moving a stdlib function, or when two modules could both own an operation.
Evidence: commit 9a2dc4e6, [process](../../../src/stdlib/os/process.ms), [fs](../../../src/stdlib/os/fs.ms), [crypto](../../../src/stdlib/crypto/crypto.ms), [sse](../../../src/stdlib/net/sse.ms).
Verify: `ms search <old name>` finds no declaration; `make docs-check` passes and every moved symbol has an updated fixture.
