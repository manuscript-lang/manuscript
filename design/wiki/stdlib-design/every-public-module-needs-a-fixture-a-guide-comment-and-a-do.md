# Every public module needs a fixture, a guide comment, and a doc comment with an example

Verified: public modules have a fixture in `tests/conformance/fixtures/e2e/stdlib/*.ms`, and all stdlib prose lives in `src/stdlib/*.ms` (book Markdown is generated by `make docs`). A new member documents its failure mode in its doc comment. The `.ms` declarations are the signature authority for the Rust runtime, which binds natives through `extern fn`.


Apply when: adding a module or public member.
Evidence: [development checks](../../../documentation/contributing/development.md), [runtime conventions](../../../documentation/contributing/runtime-conventions.md), docgen.
Verify: `make docs-check` (add `make docs-coverage` for doc-comment coverage) and `make conform`.
