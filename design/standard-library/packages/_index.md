# General-purpose packages

[Standard library guide](../_index.md) · [Package coverage](coverage.md)

These packages extend the core data, concurrency, and host contracts without adding language syntax. The [coverage map](coverage.md) records functional equivalents and deliberate exclusions; the [common contract](contracts.md) governs errors, limits, and authority. Signatures here specify standard native bindings, not complete source modules.
