# @std/errors.ms

Import each required symbol with `import Name from "@std/errors.ms"`.

## LibraryError

Kind: alternative.

```text
LibraryError: LibraryError
case InvalidInput
case InvalidData
case OutOfRange
case LimitExceeded
case NotFound
case AlreadyExists
case PermissionDenied
case Unsupported
case Closed
case Timeout
case AuthenticationFailed
case Failed(message: String)
```
