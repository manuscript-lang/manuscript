# Language basics

[Core language guide](../_index.md) · [Design index](../../_index.md)

Start with the shape of a source file, then learn how names and common values behave. These concepts are enough to read a small function and follow its local calculations.

| Concept | What you will learn |
| --- | --- |
| [Source structure and syntax](syntax.md) | Read a source file, indentation, comments, and multiline expressions. |
| [Source grammar](grammar.md) | Check the exact accepted tokens, declarations, suites, and patterns. |
| [Expressions and operators](expressions.md) | Apply precedence, operand types, and evaluation order. |
| [Bindings and scope](bindings.md) | Choose let or var, infer local types, and understand shadowing. |
| [Destructuring bindings](destructuring.md) | Bind positions and record fields with bracket and brace patterns. |
| [Numbers and booleans](numbers-and-booleans.md) | Use numeric literals, explicit conversions, checked arithmetic, and durations. |
| [Strings and bytes](text-and-bytes.md) | Interpolate text, encode UTF-8, and distinguish character boundaries. |
