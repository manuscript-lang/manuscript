# Functions

[Core language guide](../_index.md) · [Design index](../../_index.md)

Functions take named inputs and return a declared type. First learn how to declare and call them. Then learn how to pass a function as a value and what it keeps from its surrounding scope.

| Concept | What you will learn |
| --- | --- |
| [Declarations and calls](declarations-and-calls.md) | Write explicit signatures and evaluate arguments in source order. |
| [Function values and closures](function-values-and-closures.md) | Pass functions as values and understand snapshot captures and resource references. |
