# Ownership (one owner, references without a marker)

`Hir::ownership()` enforces the memory model of `crates/DESIGN.md` (decision 1, as amended 2026-11-01 by `proposals/reference-ownership.md`) and exposes the moves, drops and borrows lowering needs. It runs on every program that type checks, and its rejections are diagnostics. Rejections carry mechanical fixes (`--json`). Conformance fixtures tagged `aliasing` rely on shared mutation and stay outside the Rust gate.

```rust
let own = program.hir().ownership();
own.diagnostics                       // rejections
let f = own.of(&callable).unwrap();   // CallableOwnership
f.use_at(name_expr.id, &binding)      // Use { access: Copy|Borrow|Mutate|Move|Write, last }
f.bindings[&binding.uid]              // BindingFacts { role, class, owned, borrows }
f.calls[&call.id]                     // CallModes { receiver, arguments, returns_receiver, .. }
f.lambdas[&lambda.id]                 // LambdaFacts { escaping, captures: [(binding, Move|Borrow|Mutate)] }
f.temporaries                         // owned values dropped at the end of their statement
f.consumed_scrutinees                 // match/if-let whose payloads own their parts
f.drops_old                           // assignments storing over a binding (drop flag; cleared by a Move)
f.parameters, f.receiver              // inferred ParamMode: Borrow | Mutate (var) | Consume
```

## Model

- **Classes.** `Copy` (primitives: scalars, `Unit`, alternatives whose cases carry only primitives, `Shared[T]` handles), `Move` (strings, records, collections and everything else owned: a record is a container of data with one owner whatever its fields), `Resource` (types with cleanup, and records, alternatives, `Optional`, `List` and `Map` values that hold one; move-only, never `.clone()`). A `List[T]` is `Resource` exactly when `T` is, a `Map[K, V]` when `V` is; a resource is not `Hashable`, so a `Set[R]` or `Map[R, V]` is rejected. `Shared[T]` (`@std/concurrency/shared.ms`) is the only reference-counted value and the only copyable handle.
- **Owned parts.** A `Resource` binding nothing moves on is closed when its scope ends, parts included: the lowering (`close.rs`, `close_with_parts`) generates one closer per type. The type's own `Closeable.close` runs first, then its parts in reverse order: record fields last declared first, the fields of the active alternative case last first, an `Optional` payload, list elements last index first, map values last inserted first (maps and sets iterate in insertion order, so no order is unspecified). A part whose type is not `Resource` adds no code. A part that already closed itself sees a second `close`, which the contract makes harmless. An owned binding whose type mentions a type parameter (`Wrap[T]`, `List[T]`) is registered for closing too; lowering closes the instance only when its type has a closer, so a plain instance costs nothing. **Copies are declared, not inferred.** A copy of a value of a type parameter requires `T: Clonable`, and `Clonable` holds for every type that is not and does not hold a resource (`contracts.rs`, `clonable`; `Data` and `Hashable` imply it). The standard methods that copy elements sit in `Clonable`-bounded interfaces (`ListCopies`, `MapCopies`, `ListOrderCopy`, `MapUpdate`), so `[door].take(1)` and a generic `xs.take(1)` fail ordinary bound checking, and a generic implementation that copies must itself be bounded. The copies the language makes without a call are checked where they are written (`require_clonable`): a function value or lambda that keeps a parameter it only borrows, and an interface conversion whose implementation keeps a parameter the operation only lends. Overwriting or removing a part of a live container closes the old part first (`r.f = x`, `xs.set`, `xs.remove`, `m.add` over an existing key, `m.remove`, `m.clear`; lowering `close_discarded`); `xs.pop()` returns it to a binding, which closes it. `splice` closes the elements it deletes; the copying methods (`fill`, `copy_within`, `merge`, `concat`, `take`, `drop`, `slice`, `reversed`, `sorted`, `filter`, `find`, `chunks`, `group_by` and the rest of `ListCopies` and `MapCopies`) require `Clonable` elements; a `Set` never holds a resource. `get(default)` on a resource-holding `Optional` or `Result` takes the payload out of its receiver and consumes it. A temporary that holds a resource (a call result read with `.f`, `[i]`, `is_some()`, or a method) is read in place and closed once at the end of its statement, parts included; moving a resource part out of such a temporary (`let d = pair().a`) is rejected: bind the whole value first. `try r` on a binding at its last use hands the payload on (the binding no longer closes it); elsewhere it reads the payload in place.
- **One owner.** A `Move`-class value stored in a new owner (consuming parameter, record/list/map element, `return` of a value that is not a part of an argument, `var y = x` of a non-`var` name, closure capture of an escaping closure) is moved. A move is legal only at the value's last use (backward liveness; loops use a head fixpoint; reassignment kills the old value). Use after move is an error. Only `.clone()` copies a `Move`-class value; the compiler never copies one implicitly.
- **Modes.** Parameter modes are inferred by a program-wide fixpoint: `Borrow` (read), `Mutate` (declared `var`), `Consume` (moved/stored/returned). `var` is declared in the signature (`var xs: T`, `var fn` receivers) and written at the call (`f(var xs)`); the marker is required exactly where the callee takes `var`. There is no `mut`.
- **Mutability.** `let` is immutable including contents; only `var` bindings, `var` parameters and `var fn` receivers change. Fields/elements of a `var` binding are changed through it.
- **Overlap.** Operands that a call keeps hold of (a `var` argument, a `Move`-class borrow, a closure capture) must not overlap: `f(var a, a)` and `f(var r, r.items)` are rejected. A `Copy` value computed before the call (`f(var xs, xs.length())`) is fine.
- **Borrows are lexical.** Payload bindings, loop variables, accessor results, `let x = a.b` / `a[i]`, `let y = x` and `let x = f(a)` of a lending call hold a borrow of their origin until the holder's last use (payload and loop borrows last the whole arm/body). While held, the origin cannot be changed, reassigned or moved (Chinmay, 2026-11-01: this stays an error; the binding does not copy). Moving out of a borrow is rejected (`.clone()` first); a field of an owned value is moved by a partial move (below). Native lends (`Map.get(k)`, `List.first()`, `List.last()`) are borrows of their receiver the same way, so `let x = m.get(k); m.remove(k)` is rejected (#2181).
- **Lending results.** A function whose every return path is a part of a parameter or the receiver (a place rooted there, a local borrowing one, or a lending call over them) lends: `Summary.result` records which arguments and, for one chain of fields of one argument, the path; the fixpoint starts optimistic and withdraws. A path returning a new value next to a lending path is an error (`return .clone() of the part`). A lent value wrapped on the way out stays a reference: `return r.tags[0]` as `String?`, `return ok(r.name)`, `return error(r.err)` and `try f(r)` handing a lent error on all lend (`view_wraps`; lowering builds the wrapper with `opt.view` / `alt.view`, which neither retain nor release their payload, so a boxed optional or alternative cannot be viewed), and `let o: Item? = item` / `let k = ok(x)` bind a borrow of the source. A wrapped lend next to a path that returns a new value is withdrawn and the function owns its result, as before, unless an unwrapped lend makes the mix an error. A value converted to an interface or a widened error type, a resource, a lambda result and an interface implementation's result are always owned; an argument converted on the way in makes the call's result a new value. A lend from a temporary makes the caller own the result (`owned_lends`): when the callee hands the whole temporary back (`id(make())`, `OwnedLend::Whole`) lowering keeps that temporary as the result instead of dropping it, no copy; a part of a temporary is copied out before the temporary drops (`OwnedLend::Copy`). At a call, a lending result is a borrow of the arguments for freezing, overlap and scrutinee purposes (`pure_origins`); consuming it (storing, returning it where the function owns its result, passing it to a consuming parameter) is an error with a `.clone()` remedy. A field or element of a lending call's result (`self.head().tags[0]`) is a part of the same sources, and a conditional or match expression whose arms all lend is one lent value (`lent_matches`: lowering joins the arms without copying; a payload of the match itself is never one of its origins, since it may end with the arm). Operands of one call, operator, index, literal or interpolation are checked against each other (`check_overlap`): a place one operand holds for the whole expression (a place argument, a lending result) clashes with a change or move of it by a `var` or consumed argument anywhere inside a sibling operand (`nested_writes`), so `two(label(r), mutate(var r))` and `label(r) + mutate(var r)` are rejected; two siblings that each finish their own change (`pushed(var xs) + pushed(var xs)`) are fine. Lowering marks the MIR function `ret_borrowed`, returns the reference as it is, and classifies call results through `Module::result_mode`.
- **Partial moves.** A field of an owned local or parameter moves out at the field's last use when the field is consumed directly: `return b.items`, `f(b.items)` for a consuming parameter, or a field of a record or element of a list built in place. Liveness is kept per place (`live.rs`, `Liveness.places`): a use of `b.items`, of a prefix (`b`) or of an extension (`b.items.x`) counts as a use of the place; a use of a sibling field does not. So `b.name` stays usable, a later use of `b.items` or of the whole `b` is `moved here but used again`, a loop that moves the place again on its next iteration is the same error, and `b.items = v` makes the place live again (later reads see `v`). Whole-binding uses after a store still count the moved parts, so move the whole binding instead. It applies to fields of records, not an element (`xs[i]`), not through a `ref` field, a borrow, a `var` binding or parameter, the receiver, a `for` or pattern variable, a closure capture, or a binding that a closure captures, and not out of a type that declares `close` (the close would see a hole). A `Resource` field moves only out of a `let` or a by-value parameter, and moves without a copy: the new owner closes it. Lowering gives such a binding one cleanup entry per resource field (`Split` in `ms-lower` `close.rs`); the move discards that field's entry and clears its flag, scope end closes the fields whose flag is still set, last declared first, and drops the other leaves with `move.out` + `drop` (never a whole-record drop). A place and a part of it cannot both be moved out of one binding. A parameter that has a field moved out of it is consumed: the caller gives it up. `let x = b.items` stays a borrow (see Borrows are lexical); it does not move. In a function declared `ref`, `return b.items` lends as before. A `Move`-class field's move is semantic: lowering still copies where the value is consumed, and the rest of `b` is released as before; removing the copy is an optimizer job (`rec.release`, `copyelim`) gated by `make count-check`.
- **Mutable borrows.** `var x = a.b` / `a[i]` of a record or collection binds an exclusive borrow of the part (`var y = x` of a `var` name borrows the whole value): changes through `x` change the origin, which must itself be changeable (`var`). A primitive is copied instead (`var n = r.n; n += 1` leaves `r.n`, #2168). While `x` is live nothing else may read, change, move or borrow the origin (so there is only one mutable borrow at a time; disjoint fields are fine). `x` cannot be reassigned or moved out, and ends at its last use. `let x = a.b` stays a shared borrow. `if var x = m[k]?` and `if var x = m.get(k)` borrow the entry in place, so `x.append(1)` changes the map (#2164); `if var` of any other optional is rejected, since changes to a copy would be lost. `var x = f(a)` of a lending call that returns one chain of fields of one argument borrows that chain (`getter_borrows`); any other lending result must be bound with `let` or cloned.
- **One borrow fact for lowering.** `Ownership.borrows` maps each binding that borrows a place to `Shared` (`let`, payloads, loop variables) or `Exclusive` (`var`). A binding of a temporary owns its value and is absent, so lowering never points a binding into storage freed at the end of the statement; lowering lends a binding (no copy, no drop) only when this fact says so.
- **Match / destructuring** consumes an owned last-use scrutinee (payloads own their parts, `consumed_scrutinees`); otherwise payloads are borrows. A parameter matched or iterated at its last use is borrowed (the function stays `Borrow` for it) unless a payload or loop variable is moved out; that move makes the scrutinee consume the parameter, found by the same fixpoint as closure escapes. `var` in a case payload is rejected.
- **Interface conversion.** A value passed where an interface is expected is converted implicitly and follows the position: a read-only argument borrows it and the interface value owns a copy (`a.compare(b)` leaves `b` usable), a stored position moves it at its last use. Interfaces are never constructed (`Iface(value: x)` is rejected). A resource may become only an interface that declares `close`; converting it to any other interface is rejected, since nothing would close it. A `Closeable` value is itself a resource: its binding, or the list, map or record holding it, closes it through the interface. Another interface with a `close` (a channel's `Transport`, a `Logger`) is a handle its holder closes explicitly. An implementation that keeps a parameter its interface operation only lends is called through the interface with a copy, so converting a value whose implementation does that is rejected when the parameter is a resource, and records a copy of the type parameter in generic code (`Summary.copies`), as a generic copy does. A temporary resource converted for a read-only argument stays owned by the statement and is closed once at its end. `Clonable` is a structural bound like `Equal`: it gives a type parameter `.clone()`, which is how a generic container returns an element it still stores.
- **Closures.** A closure that is returned, stored or passed to a consuming parameter *escapes*: it owns its captures (moved at creation, so the captured variable is dead afterwards) and may not change them or move them out when called (it can run many times: return `x.copy()`). A non-escaping closure borrows its captures lexically; one that changes a capture borrows it exclusively, and lowering gives that variable a memory slot the closure reads and writes through (`slotted` in `ms-lower`). Escape is inferred per module by fixpoint; native callbacks on collections are non-escaping. A function value is called with its arguments lent: a lambda cannot move a resource parameter out (taking it would copy it while the caller still closes it), and a named function or method that keeps a resource parameter cannot be used as a value; in generic code either records a copy of the type parameter. A native that runs a callback on an owned temporary's payload (`maybe().map(..)`, `open().get_or_else(..)`) closes the temporary afterwards.
- **Mutators** (`append`, `set`, ...) take their receiver `var` and return `Unit`-like unusable results: chaining and using the result are errors.
- **`.clone()`** is the temporary spelling of `.copy()` (deep value copy); diagnostics say `.clone()` until the rename (`COPY` constant in `walk.rs`).

## Open decisions: resolved here

| Decision | Resolution |
| --- | --- |
| Projections vs copies | Projections (`a.b`, `a[i]`, accessors, payloads) **borrow**; they cannot be changed through a `let`, and move out only as a partial move of a field of an owned value; `.copy()` produces an owned value. |
| Mutator results | Unusable (statement position only); no chaining. |
| Closure escape | Escaping closures own captures (move at creation, no mutation/move-out of captures in the body); others borrow. Inferred per module. |
| Generic copyability | Type variables are `Move`; no `Copy` bound. Monomorphization may copy when the instance is `Copy`-class. |
| Handle types | `Copy`-class handles; resources are `Resource` (move-only, no `.copy()`). |

## String views

`trim`, `trim_start` and `trim_end` return an owned `String`. Lowering elides the copy when the receiver is a variable that stays unchanged for the result's whole life (`trim_view` in `ms-lower`), so a result that is only read allocates nothing, and one that is stored or returned is a real copy. The checker applies no borrow rule to it.

## Behavior changes for the migration tool

Programs written for reference semantics change as follows:

1. **Aliasing is explicit.** `let b = a` borrows (`b` is a read-only view that blocks changes to `a` while `b` is used) or moves at `a`'s last use; `var b = a` of a `var` borrows it exclusively. Code relying on two names changing one object independently must `.clone()`.
2. **`.clone()` is deep** and renamed `.copy()`; `.clone()` for a cheap shallow share becomes a borrow (or, once planned `Shared[T]` exists, a `Shared[T]`).
3. **Mutator chaining/results** (`xs.append(1).append(2)`, `values.prepend(0).set(1, 9)`) become separate statements; results of mutators are not values.
4. **Implicit parameter mutation.** A function that changes a parameter declares it `var` and every caller writes `var` at the argument.
5. **`let` is deeply immutable.** `let xs = []; xs.append(1)` becomes `var xs`.
6. **Closure capture is by borrow or move,** not by snapshot of a shared reference; a closure that mutates its capture exclusively borrows it, an escaping one owns it.
7. **Iteration while mutating** the iterable (`for v in xs: xs.fill(..)`) is rejected.
8. **Accessor-then-mutate** (`let first = xs[0]; xs.append(..); use(first)`, also through `Map.get`, `first`, `last` and any lending function) is rejected; `.clone()` the part or finish using it first.
9. **Field assignment through calls/borrows** (`receiver(log, v).val = ...`, `let alias = rec; alias.f = 1`) is rejected; assign through the owning `var`.

## Limits

- Indexed assignment `xs[i] = v` has no syntax yet (`set` is the mutator).
- `var` parameters, `var` call arguments and `var fn` are syntax additions (`ms-syntax`: `Param.mutable`, `Argument.mutable`, `Method.mutating`).
- Native modes come from `collection_mutation` plus type-shape heuristics; a native that consumes an argument without a collection signature is treated as `Borrow`.
- Moved-on-every-path is not tracked forward: `drops_old` is a may-drop fact paired with a drop flag cleared at `Move` uses.
- Impl-vs-interface mode agreement is not checked yet.
