# Ownership (one owner, references without a marker)

`Hir::ownership()` enforces the memory model of `crates/DESIGN.md` (decision 1, as amended 2026-11-01 by `proposals/reference-ownership.md`) and exposes the moves, drops and borrows lowering needs. It runs on every program that type checks, and its rejections are diagnostics. Rejections carry mechanical fixes (`--json`). Conformance fixtures tagged `aliasing` rely on shared mutation and stay outside the Rust gate.

```rust
let own = program.hir().ownership();
own.diagnostics                       // rejections
let f = own.of(&callable).unwrap();   // CallableOwnership
f.use_at(name_expr.id, &binding)      // Use { access: Copy|Borrow|Mutate|Move|Write, last }
f.bindings[&binding.uid]              // BindingFacts { role, class, owned, borrows }
f.calls[&call.id]                     // CallModes { receiver, arguments, returns_receiver, .. }
f.lambdas[&lambda.id]                 // LambdaFacts { escaping, captures: [(binding, Move|Borrow|Mutate)] }
f.temporaries                         // owned values dropped at the end of their statement
f.drops_old                           // assignments storing over a binding (drop flag; cleared by a Move)
f.parameters, f.receiver              // inferred ParamMode: Borrow | Mutate (var) | Consume
```

## Model

- **Classes.** `Copy` (primitives: scalars, `Unit`, alternatives whose cases carry only primitives), `Move` (strings, records, collections and everything else owned: a record is a container of data with one owner whatever its fields), `Resource` (types with cleanup, and records, alternatives, `Optional`, `List` and `Map` values that hold one; move-only, never `.clone()`). A `List[T]` is `Resource` exactly when `T` is, a `Map[K, V]` when `V` is; a resource is not `Hashable`, so a `Set[R]` or `Map[R, V]` is rejected.
- **Owned parts.** A `Resource` binding nothing moves on is closed when its scope ends, parts included: the lowering (`close.rs`, `close_with_parts`) generates one closer per type. The type's own `Closeable.close` runs first, then its parts in reverse order: record fields last declared first, the fields of the active alternative case last first, an `Optional` payload, list elements last index first, map values last inserted first (maps and sets iterate in insertion order, so no order is unspecified). A part whose type is not `Resource` adds no code. A part that already closed itself sees a second `close`, which the contract makes harmless. An owned binding whose type mentions a type parameter (`Wrap[T]`, `List[T]`) is registered for closing too; lowering closes the instance only when its type has a closer, so a plain instance costs nothing. **Copies are declared, not inferred.** A copy of a value of a type parameter requires `T: Clonable`, and `Clonable` holds for every type that is not and does not hold a resource, where a native counts only when it declares an infallible `clone` of its own (`List`, `Bytes`, `BigInt`) or is `Decimal` (plain words): a `Regex` or a `Pipe` is not `Clonable` and has no `.clone()` (`contracts.rs`, `clonable`, mirrored by `ownership::Classifier::clonable`; `Data` and `Hashable` imply it). The standard methods that copy elements are receiver methods with a `Clonable` bound on the element type (`fn List[T: Clonable].take`, `fn Map[T: Hashable, U: Clonable].merge`), so `[door].take(1)` and a generic `xs.take(1)` fail ordinary bound checking, and a generic implementation that copies must itself be bounded. The copies the language makes without a call are checked where they are written (`require_clonable`): a function value or lambda that keeps a parameter it only borrows, and an interface conversion whose satisfying method keeps a parameter the operation only borrows. Overwriting or removing a part of a live container closes the old part first (`r.f = x`, `xs.set`, `xs.remove`, `m.add` over an existing key, `m.remove`, `m.clear`; lowering `close_discarded`); `xs.pop()` returns it to a binding, which closes it. `splice` closes the elements it deletes; the copying methods (`fill`, `copy_within`, `merge`, `concat`, `take`, `drop`, `slice`, `reversed`, `sorted`, `filter`, `find`, `chunks`, `group_by` and the other `Clonable`-bound `List` and `Map` methods) require `Clonable` elements; a `Set` never holds a resource. `get(default)` on an `Optional` or `Result` whose payload has one owner (a resource, or a concrete type that is not `Clonable`, such as a native without a `clone`) takes the payload out of its receiver and moving_params it; a borrowing read (`xs.first()`) stays a borrow. A temporary that holds a resource (a call result read with `.f`, `[i]`, `is_some()`, or a method) is read in place and closed once at the end of its statement, parts included; moving a resource part out of such a temporary (`d := pair().a`) is rejected: bind the whole value first. `r?` on a binding at its last use hands the payload on (the binding no longer closes it); elsewhere it reads the payload in place.
- **One owner.** A `Move`-class value stored in a new owner (moving parameter, record/list/map element, `return` of a value that is not a part of an argument, `var y = x` of a non-`var` name, closure capture of an escaping closure) is moved. A move is legal only at the value's last use (backward liveness; loops use a head fixpoint; reassignment kills the old value). Use after move is an error. Only `.clone()` copies a `Move`-class value; the compiler never copies one implicitly.
- **Modes.** Parameter modes are inferred by a program-wide fixpoint: `Borrow` (read), `Mutate` (declared `var`), `Consume` (moved/stored/returned). `var` is declared in the signature (`var xs: T`, `var fn` receivers) and written at the call (`f(var xs)`); the marker is required exactly where the callee takes `var`. There is no `mut`.
- **Mutability.** `:=` is immutable including contents; only `var` bindings, `var` parameters and `var fn` receivers change. Fields/elements of a `var` binding are changed through it.
- **Overlap.** Operands that a call keeps hold of (a `var` argument, a `Move`-class borrow, a closure capture) must not overlap: `f(var a, a)` and `f(var r, r.items)` are rejected. A `Copy` value computed before the call (`f(var xs, xs.length())`) is fine.
- **Borrows are lexical.** Payload bindings, loop variables, accessor results, `x := a.b` / `a[i]`, `y := x` and `x := f(a)` of a borrow-returning call hold a borrow of their origin until the holder's last use (payload and loop borrows last the whole arm/body). While held, the origin cannot be changed, reassigned or moved (Chinmay, 2026-11-01: this stays an error; the binding does not copy). Moving out of a borrow is rejected (`.clone()` first); a field of an owned value is moved by a partial move (below). Native borrows (`Map.get(k)`) and stdlib bodies that return part of their receiver (`List.first()`, `List.last()`) are borrows of their receiver the same way, so `x := m.get(k); m.remove(k)` is rejected (#2181).
- **Borrow-returning functions.** A function whose every return path is a part of a parameter or the receiver (a place rooted there, a local borrowing one, or a borrow-returning call over them) returns a borrow: `Summary.result` records which arguments and, for one chain of fields of one argument, the path; the fixpoint starts optimistic and withdraws. A path returning a new value next to a borrow-returning path is an error (`return .clone() of the part`). `return m.get(k)` on a `Map` returns a borrow of the map's entry as an `opt.view` (Chinmay, 2026-11-07; `xs.first()` / `xs.last()` are stdlib bodies that return `none` or `self.get(i)` and borrow the same way, a bare `none` not cancelling the borrow), so a caller holding the result cannot change the map: `.clone()` it first. A borrowed value wrapped on the way out stays a reference: `return r.tags[0]` as `String?`, `return ok(r.name)`, `return error(r.err)` and `f(r)?` handing a borrowed error on all return a borrow (`view_wraps`; lowering builds the wrapper with `opt.view` / `alt.view`, which neither retain nor release their payload, so a boxed optional or alternative cannot be viewed: an instance whose result is a boxed optional returns an owned copy instead, and its caller drops it), and `o: Item? = item` / `k := ok(x)` bind a borrow of the source. A wrapped borrow of one case of a `Result` next to paths that build only the other cases (`value?` beside `return ok(output + "x")`, `return ok(found)` beside `return error(failure(..))`) makes a *borrowing result* (`ResultBorrow.borrowed_cases`, `BORROWED_OK` / `BORROWED_ERROR`, facts `Fact::BorrowedOk` / `Fact::BorrowedError`): the cases the function owns are owned, the others borrow the arguments, the caller holds the sources while the result lives and drops only the owned cases. MIR gives such a result a *borrowing variant* of the alternative (`AltDef.borrowed`, `Module::borrowing_alt`: same layout and cases, drop glue skips the borrowed cases; `alt.view` fills a borrowed case, `alt.new` an owned one, the verifier checks both and rejects `alt.take` / `alt.release` of a borrowed case), read as the ordinary alternative where one is expected (`alt.plain`, a borrow) and copied into it where an owner is needed (`alt.own`, only for a borrowed temporary source and Result natives that return an owned payload). `?` on a borrowing result relays a borrowed error as a borrow and borrows a borrowed `ok` payload; a borrowing result returned whole (`return expect_ok(actual)`) is the same borrowing result. A wrapped borrow beside a path that builds the same case, an unknown shape, a resource closed at scope end (its close error is an owned error), or a part that has one owner and no `clone` is withdrawn and the function owns its result, as before, unless an unwrapped borrow makes the mix an error; once withdrawn, a wrapped part whose type is not `Clonable` is moved out instead of copied on the next round (`moves_withdrawn_borrow`), which moving_params the argument it came from (`http_result[T](outcome: T!)` returning `ok(found)` beside a new error moving_params `outcome`). A borrowed value converted to an interface on the way out (`return cause` as `Error`, `error(cause)` as `Int!`, a widened borrow-returning call, `?` on one) makes the function a *borrow-returning view function* (`ResultBorrow.view`, MIR `ret_view`): the result is an owned interface view (`iface.borrow`: a box holding the borrowed leaves as they are, vtable word tagged 1, so dropping it frees only the box) whose payload stays in the arguments; the caller drops the result and holds the arguments while it lives, exactly as for a plain borrow-returning function. A path returning a new value is allowed beside a view (both are owned); a plain reference beside one is handed on as a view that owns nothing (`iface.view`, tag 2) when the result type is an interface and is an error otherwise. `e: Error = cause`, `r: Int! = error(cause)` and `e := first_error(cause)` bind *view locals* (`view_locals`): the binding owns the box and borrows `cause`; returning such a local moves the box out (`view_moves`), as does `return relay(e)` handing it on whole; `e2 := e` at `e`'s last use hands the box to `e2` (a view local too), while `e2 := e` with `e` used later is a plain reference into `e`'s box, so returning or relaying `e2` is rejected; storing a view local needs an owned conversion (`e: Error = cause.clone()`). A resource, a lambda result and an interface implementation's result are always owned; an argument converted on the way in makes the call's result a new value. A conversion to an interface that declares a `var fn` (`WriteStream`, `ReadStream`) is never a view: a call through it, by a native such as `copy`, would change leaves the view only borrows, so it copies as before (`contract_mutates`). A borrow from a temporary makes the caller own the result (`owned_borrows`): when the callee hands the whole temporary back (`id(make())`, `OwnedBorrow::Whole`) lowering keeps that temporary as the result instead of dropping it, no copy; a part of a temporary is copied out before the temporary drops (`OwnedBorrow::Clone`), which is rejected when the result type is not `Clonable` (`cloned_borrow`): bind the argument first and use the result while that binding lives. At a call, a returned borrow is a borrow of the arguments for freezing, overlap and scrutinee purposes (`pure_origins`); consuming it (storing, returning it where the function owns its result, passing it to a moving parameter) is an error with a `.clone()` remedy. A field or element of a borrow-returning call's result (`self.head().tags[0]`) is a part of the same sources, and a conditional or match expression whose arms all return a borrow is one borrowed value (`borrowed_matches`: lowering joins the arms without copying; a payload of the match itself is never one of its origins, since it may end with the arm). Operands of one call, operator, index, literal or interpolation are checked against each other (`check_overlap`): a place one operand holds for the whole expression (a place argument, a returned borrow) clashes with a change or move of it by a `var` or consumed argument anywhere inside a sibling operand (`nested_writes`), so `two(label(r), mutate(var r))` and `label(r) + mutate(var r)` are rejected; two siblings that each finish their own change (`pushed(var xs) + pushed(var xs)`) are fine. Lowering marks the MIR function `ret_borrowed`, returns the reference as it is, and classifies call results through `Module::result_mode`.
- **Partial moves.** A field of an owned local or parameter moves out at the field's last use when the field is consumed directly: `return b.items`, `f(b.items)` for a moving parameter, or a field of a record or element of a list built in place. Liveness is kept per place (`live.rs`, `Liveness.places`): a use of `b.items`, of a prefix (`b`) or of an extension (`b.items.x`) counts as a use of the place; a use of a sibling field does not. So `b.name` stays usable, a later use of `b.items` or of the whole `b` is `moved here but used again`, a loop that moves the place again on its next iteration is the same error, and `b.items = v` makes the place live again (later reads see `v`). Whole-binding uses after a store still count the moved parts, so move the whole binding instead. It applies to fields of records, not an element (`xs[i]`), not through a borrowed field projection, a borrow, a `var` binding or parameter, the receiver, a `for` or pattern variable, a closure capture, or a binding that a closure captures, and not out of a type that declares `close` (the close would see a hole). A `Resource` field moves only out of a `:=` or a by-value parameter, and moves without a copy: the new owner closes it. Lowering gives such a binding one cleanup entry per resource field (`Split` in `ms-lower` `close.rs`); the move discards that field's entry and clears its flag, scope end closes the fields whose flag is still set, last declared first, and drops the other leaves with `move.out` + `drop` (never a whole-record drop). A place and a part of it cannot both be moved out of one binding. A parameter that has a field moved out of it is consumed: the caller gives it up. `x := b.items` stays a borrow (see Borrows are lexical); it does not move. When the result is inferred to borrow from a parameter, `return b.items` returns that borrow. A `Move`-class field's move is semantic: lowering still copies where the value is consumed, and the rest of `b` is released as before; removing the copy is an optimizer job (`rec.release`, `copyelim`) gated by `make count-check`.
- **Mutable borrows.** `var x = a.b` / `a[i]` of a record or collection binds an exclusive borrow of the part (`var y = x` of a `var` name borrows the whole value): changes through `x` change the origin, which must itself be changeable (`var`). A primitive is copied instead (`var n = r.n; n += 1` leaves `r.n`, #2168). While `x` is live nothing else may read, change, move or borrow the origin (so there is only one mutable borrow at a time; disjoint fields are fine). `x` cannot be reassigned or moved out, and ends at its last use. `x := a.b` stays a shared borrow. `if var x = m[k]?` and `if var x = m.get(k)` borrow the entry in place, so `x.append(1)` changes the map (#2164), and for a scalar entry `n += 1` writes the entry back (the map is the origin, since a copy would lose the write); `if var` of any other optional is rejected, since changes to a copy would be lost. `var x = f(a)` of a borrow-returning call that returns one chain of fields of one argument borrows that chain (`getter_borrows`); any other returned borrow must be bound with `:=` or cloned.
- **One borrow fact for lowering.** `Ownership.borrows` maps each binding that borrows a place to `Shared` (`:=`, payloads, loop variables) or `Exclusive` (`var`). A binding of a temporary owns its value and is absent, so lowering never points a binding into storage freed at the end of the statement; lowering borrows a binding (no copy, no drop) only when this fact says so.
- **Match / destructuring** moving_params an owned last-use scrutinee (an `Access::Move` use of the local: payloads own their parts); otherwise payloads are borrows. A parameter matched or iterated at its last use is borrowed (the function stays `Borrow` for it) unless a payload or loop variable is moved out; that move makes the scrutinee consume the parameter, found by the same fixpoint as closure escapes. `var` in a case payload is rejected.
- **Interface conversion.** A value passed where an interface is expected is converted implicitly and follows the position: a read-only argument borrows it and the interface value is a view of it (`iface.borrow`, no copy; `a.compare(b)` leaves `b` usable), a stored position moves it at its last use. A plain borrow-returning function that hands a converted argument back whole (`relay(cause)` for `relay(e: Error) Error`) gives the caller the view temporary as its result (`OwnedBorrow::Whole`), which borrows `cause`. Interfaces are never constructed (`Iface(value: x)` is rejected). A resource may become only an interface that declares `close`; converting it to any other interface is rejected, since nothing would close it. A `Closeable` value is itself a resource: its binding, or the list, map or record holding it, closes it through the interface. Another interface with a `close` (a channel's `Transport`, a `Logger`) is a handle its holder closes explicitly. An implementation that keeps a parameter its interface operation only borrows is called through the interface with a copy, so converting a value whose implementation does that is rejected when the parameter is a resource, and records a copy of the type parameter in generic code (`Summary.copies`), as a generic copy does. A temporary resource converted for a read-only argument stays owned by the statement and is closed once at its end. `Clonable` is a structural bound like `Equal`: it gives a type parameter `.clone()`, which is how a generic container returns an element it still stores.
- **Closures.** A closure that is returned, stored or passed to a moving parameter *escapes*: it owns its captures (moved at creation, so the captured variable is dead afterwards) and may not change them or move them out when called (it can run many times: return `x.copy()`). A non-escaping closure borrows its captures lexically; one that changes a capture borrows it exclusively, and lowering gives that variable a memory slot the closure reads and writes through (`slotted` in `ms-lower`). Escape is inferred per module by fixpoint; native callbacks on collections are non-escaping. A function value is called with its arguments borrowed: a lambda cannot move a resource parameter out (taking it would copy it while the caller still closes it), and a named function or method that keeps a resource parameter cannot be used as a value; a kept parameter of a concrete type that is not `Clonable` (a native without a `clone`) is rejected the same way (`require_clonable`), and in generic code either records a copy of the type parameter. A kept parameter of an interface type still copies (`HttpExchange` in a middleware `Tap`): the interface does not name its payload's type, so the runtime guards the copy, faulting for a payload with one owner, until wrappers can borrow. A native that runs a callback on an owned temporary's payload (`maybe().map(..)`, `open().get_or_else(..)`) closes the temporary afterwards. A method value (`re.find`, `log.error[Unit]`) is a closure over its receiver and follows the same rule: while it stays local it borrows the receiver's place (`bound_borrows`; lowering captures the receiver's address, the variable's own slot or a frame slot holding the borrowed value, and the thunk loads it), and when it escapes it takes the receiver, moving it at its last use with the usual `.clone()` remedy. A `Copy` receiver or a temporary one is held by value. A method value that changes its receiver (`xs.append`) borrows the variable exclusively and never escapes.
- **Promises.** A call of a source function or method that returns a `Promise` (`@std/concurrency/promise.ms`) and is given a lambda starts concurrent code, declared by that result type and not by the callee's name. The lambda reads its captures in place; it is never an escaping closure and moves nothing. Rule 5 of the concurrency design: the lambda may not change a captured variable, call a `var fn` on it or pass it as `var` (`concurrent code never changes a shared value`); values it builds inside stay its own. The binding that holds the promise (`p := promise(fn: f(xs))`) keeps a borrow of every capture until the end of its scope, not its last use, because dropping the promise is what ends the work. Moving the promise away at its last use hands the borrow to its new holder (`all := [p, q]`, `tasks.append(p)`, a lambda that returns `q` bound by `ps := xs.map(..)`): the holder keeps it to its own scope end, and a move into a consumer with no holder (`wait_all([p, q])`) ends it. The new holder gets the places still in scope (`take_carried`); a promise moved into a record field or a call result that is not bound is not carried yet. `return promise(fn: f(xs))`, or returning a binding that holds such a borrow, is rejected when a capture is not a scalar, since the promise would outlive it. A promise a lambda starts (`ps := xs.map(fn x: promise(fn: f(x)))`, or bound inside the lambda and returned) is carried out with the same rule: `ps` borrows the lambda's outer captures to the end of its scope. Lowering contract for the runtime: the entry lambda's facts are non-escaping (`escaping: false`, captures `Borrow`) but the promise keeps the closure object alive until it ends, so its environment must be heap allocated. Lint `MSL115` reports a promise dropped as soon as it is made.
- **Mutators** (`append`, `set`, ...) take their receiver `var` and return `Unit`-like unusable results: chaining and using the result are errors.
- **`.clone()`** is the deep duplicate of an owned value and the only explicit one; diagnostics say `.clone()` (`CLONE` constant in `walk.rs`).

## Open decisions: resolved here

| Decision | Resolution |
| --- | --- |
| Projections vs clones | Projections (`a.b`, `a[i]`, accessors, payloads) **borrow**; they cannot be changed through a `:=`, and move out only as a partial move of a field of an owned value; `.clone()` produces an owned value. |
| Mutator results | Unusable (statement position only); no chaining. |
| Closure escape | Escaping closures own captures (move at creation, no mutation/move-out of captures in the body); others borrow. Inferred per module. |
| Generic copyability | Type variables are `Move`; no `Copy` bound. Monomorphization may copy when the instance is `Copy`-class. |
| Handle types | `Copy`-class handles; resources are `Resource` (move-only, no `.clone()`). |

## String views

`trim`, `trim_start` and `trim_end` return an owned `String`. Lowering elides the copy when the receiver is a variable that stays unchanged for the result's whole life (`trim_view` in `ms-lower`), so a result that is only read allocates nothing, and one that is stored or returned is a real copy. The checker applies no borrow rule to it.

## Behavior changes for the migration tool

Programs written for reference semantics change as follows:

1. **Aliasing is explicit.** `b := a` borrows (`b` is a read-only view that blocks changes to `a` while `b` is used) or moves at `a`'s last use; `var b = a` of a `var` borrows it exclusively. Code relying on two names changing one object independently must `.clone()`.
2. **`.clone()` is deep**; a cheap shallow share is a borrow.
3. **Mutator chaining/results** (`xs.append(1).append(2)`, `values.prepend(0).set(1, 9)`) become separate statements; results of mutators are not values.
4. **Implicit parameter mutation.** A function that changes a parameter declares it `var` and every caller writes `var` at the argument.
5. **`:=` is deeply immutable.** `xs := []; xs.append(1)` becomes `var xs`.
6. **Closure capture is by borrow or move,** not by copying a shared reference; a closure that mutates its capture exclusively borrows it, an escaping one owns it.
7. **Iteration while mutating** the iterable (`for v in xs: xs.fill(..)`) is rejected.
8. **Accessor-then-mutate** (`first := xs[0]; xs.append(..); use(first)`, also through `Map.get`, `first`, `last` and any borrow-returning function) is rejected; `.clone()` the part or finish using it first.
9. **Field assignment through calls/borrows** (`receiver(log, v).val = ...`, `alias := rec; alias.f = 1`) is rejected; assign through the owning `var`.

## Limits

- Indexed assignment `xs[i] = v` has no syntax yet (`set` is the mutator).
- `var` parameters, `var` call arguments and `var fn` are syntax additions (`ms-syntax`: `Param.mutable`, `Argument.mutable`, `Method.mutating`).
- Native modes come from `collection_mutation` plus type-shape heuristics; a native that moving_params an argument without a collection signature is treated as `Borrow`.
- Moved-on-every-path is not tracked forward: `drops_old` is a may-drop fact paired with a drop flag cleared at `Move` uses.
- Impl-vs-interface mode agreement: the `var` mode of every parameter must match the interface declaration (`implementation operation signature does not match contract`, `tests/interface_modes.rs`); a parameter an implementation keeps that the interface only borrows is the copy rule above (`require_clonable`). The two `Clonable` rules (`contracts.rs`, `Classifier::clonable`) are held equal by `tests/clonable_agreement.rs`.
