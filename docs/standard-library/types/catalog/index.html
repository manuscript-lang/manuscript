      Core and standard types#

      Guide index · Chapter index · Design index

      Use this table to find a type’s meaning and import path. “Implicit intrinsic” means the type is available without an import. Import other type names from the listed module when you use them in source.

      TypeMeaningImport from
      Booltrue or falseImplicit intrinsic
      IntSigned 64-bit integer; checked arithmeticImplicit intrinsic
      FloatIEEE 754 binary64Implicit intrinsic
      DecimalBase-10, 34 significant digits; round half to even@std/decimal.ms
      StringImmutable, valid UTF-8 textImplicit intrinsic
      BytesImmutable byte sequence@std/bytes.ms
      UnitOne value, unitImplicit intrinsic
      NeverNo possible valueImplicit intrinsic
      List[T], Map[K, V], Set[T]Immutable homogeneous collections with their declared sharing bounds@std/collections.ms
      MapEntry[K, V]Immutable standard record with key: K and value: V; map iteration yields entries@std/collections.ms
      Optional[T]some(value: value) or none@std/optional.ms
      Result[T, E]ok(value: value) or error(cause: cause)@std/result.ms
      ExecutionErrorJoined-group timeout or crash@std/tasks.ms
      BackgroundSynchronized service managing work under a fixed lifetime@std/tasks.ms
      WorkStatus, StartError, BackgroundFailureBackground status, admission failure, and failure reports@std/tasks.ms
      OperationIdIdentity of a runtime operation, used for diagnostics and Background status/cancellation@std/tasks.ms
      CloseableStandard close() -> Unit cleanup contract@std/cleanup.ms
      File, ReadStream, WriteStreamResource contracts; standard host values use shared views with synchronized lifecycle checks@std/io.ms
      Duration, InstantChecked nanosecond duration and monotonic clock instant@std/time.ms
      ProcessCLI authority roots@std/cli.ms
      Files, IoErrorFile capability contract and expected I/O failures@std/io.ms
      ClockMonotonic clock capability contract@std/time.ms

      Functions and closures are ordinary values; runtime tasks are not exposed as source ownership types. Fixed parallel result packs preserve positional types and use bracket destructuring; they are not homogeneous lists.

      References do not extend an object’s open lifetime. Use with for deterministic release and Result for expected operation failures. See parallel , background services , and Closeable .

      The standard API contract defines visibility, signatures, optional arguments, and pack typing.

      General-purpose types#

      The package guide adds opaque BigInt (@std/bigint.ms), Regex (@std/regex.ms) and wall-clock Timestamp (@std/time.ms); JsonValue/JsonLimits (@std/json.ms); structured format/filesystem/archive records; and LibraryError (@std/errors.ms). New capability contracts are FileSystem, Entropy, WallClock and System, supplied by explicit CLI Process fields. TCP/TLS Connection, Listener and DatagramSocket are acquired through the existing Network authority. All names remain individually imported; no additions enter the intrinsic prelude. See coverage for implemented equivalents and remaining gaps.
