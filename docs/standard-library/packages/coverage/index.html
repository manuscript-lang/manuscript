      Node.js and Go coverage

      Node.js and Go coverage#

      Standard library guide · Coverage · Common contracts

      This table maps common Node.js and Go tasks to Manuscript facilities. It tells you what runs today and what remains future work. The mapping is about functionality, not compatibility with those platforms’ APIs.

      Node.js / Go capabilityManuscript optionAvailability
      Buffer, bytes, encoding/hex/base64/binaryImmutable Bytes, strict UTF-8/hex/base64, binary Int/FloatImplemented
      strings, Unicode scalar operations, regexpText functions and opaque RE2-style RegexImplemented; normalization/graphemes/legacy encodings deferred
      Array/Map/Set, slices/maps/sortImmutable collections, sequential map/filter/fold/stable sort, buildersImplemented
      Math, strconv, math/bigFloat math, strict number conversion, BigInt, existing DecimalImplemented; complex/advanced distributions deferred
      JSON, encoding/json/csv, net/url, htmlExact-number JsonValue, bounded CSV, ordered query codecs, URL records, escapingImplemented
      path/filepath, fs/io/fsNative pure paths, explicit read/write/copy/stat/list/create/remove/rename/linksImplemented; seek/watch/permissions APIs deferred
      stream, io, bufio/readlineExisting ReadStream/WriteStream plus bounded copy/read_all/read_lineImplemented functional option; no Node stream events
      time/timers/os/process infoMonotonic Clock/sleep, wall Timestamp, System snapshots/environmentImplemented; timezone/calendar/ticker APIs deferred
      crypto/crypto/randEntropy, UUID, unbiased integers, SHA/HMAC/PBKDF2, AES-GCM, Ed25519Implemented; broader algorithms/key containers deferred
      net/dgram/dnsTCP/Unix sockets, UDP, bounded DNS A/AAAA/CNAME/MX/NS/TXT/PTR/SRV, scoped resolver and destination policyImplemented
      tls/httpsVerified TLS, custom trust/client certificates, mutual TLS listener, certificate parsing/verification and negotiated metadataImplemented
      http/net/httpBuffered and streaming HTTP/1.1/HTTP/2, pooled clients, cookies, redirects, WebSocket sessionsImplemented; HTTP/3 excluded by user request
      child_process/os/execExisting Commands.run, bounded captured output, timeout, joined executionImplemented functional option; interactive child handles deferred
      zlib/compress, archive/tar/zipBounded gzip/zlib/deflate, ZIP/TAR immutable encode/decodeImplemented; extraction/Brotli/Zstd deferred
      events/sync/channels/context/worker_threadsQueue, State, Pool/Lease, joined parallel and Background contextsImplemented; no JS worker VM or detached tasks
      console/log/assert/testingExplicit streams/structured JSON log, equality/tolerance assertions, existing runnerImplemented; interactive terminal and advanced diagnostics deferred
      XML/gob/ASN.1/MIME/image/database/sqlApplication/adaptor implementations using Bytes/streams/capabilitiesDeferred; not claimed as standard-package coverage
      vm/v8/module/async_hooks/inspector/repl, Go reflect/unsafe/plugin/syscallOrdinary suspending functions, checked source tooling, trusted host adaptersRuntime-specific APIs omitted; no sandbox VM equivalent claimed

      The canonical callable surface lives on the linked package pages. Existing host/service APIs retain their identities. Deferred entries stay explicit; future implementations should add declarations to the Manuscript standard library sources and matching native implementations, semantic/boundary tests, and source-level compiler conformance fixtures together. The distribution remains self-contained with pinned vendored Go dependencies; native builds need no downloads.
