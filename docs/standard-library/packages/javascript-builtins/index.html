    JavaScript built-in coverage#

    Standard library guide · Package coverage · Implemented signatures

    The inventory follows MDN’s JavaScript reference , particularly Array , String , Map , Set , and Number . Rows identify runnable equivalents; names and contracts follow Manuscript’s type system. Deprecated HTML string wrappers and prototype machinery are excluded from the useful data API.

    List / Array#

    Import List for bracket literals. All updates return new values. Callbacks run sequentially and may suspend; use the separate parallel_map API for joined concurrency.

    JavaScript surfaceManuscript equivalentContract
    length, indexed access, atlength(), get(index:), at(index:)get rejects negative indexes; at counts from the end; missing values are Optional
    concat, push, unshiftconcat(values:), append(value:), prepend(value:)Immutable updates; concat accepts a homogeneous list
    pop, shiftlast() / first() plus without(index:)Retrieval and removal are explicit operations
    includes, indexOf, lastIndexOfcontains(value:), index_of(value:), last_index_of(value:)Element type must satisfy Equal; missing indexes are none
    find, findLast, findIndex, findLastIndexfind, find_last, find_index, find_last_index with predicate:Short-circuit search; reverse search visits from the end
    some, everysome(predicate:), every(predicate:)Empty list produces false / true respectively
    filter, map, flatMapfilter(predicate:), map(transform:), flat_map(transform:)Map may change the element type; flat_map flattens one level
    flatimported flatten(values:)One level of homogeneous nested lists; compose for deeper flattening
    reduce, reduceRightfold(initial:, step:), fold_right(initial:, step:)Always supply an initial accumulator; accumulator type may differ from element type
    forEachfor_each(operation:)Callback returns Unit

    Multi-parameter calls require argument labels; single-parameter methods and callbacks may omit the call label. Callback declarations retain their parameter names: fn(value: T) -> U, fn(value: T) -> Bool, or fn(accumulator: A, value: T) -> A. For an index-aware callback, use list.entries() and its typed ListEntry values. There is no implicit this, sparse slot, callback arity coercion, default comparator, or heterogeneous list.

    Native methods introduce only their own output/accumulator variables. Inference uses supplied arguments rather than the surrounding expected result. Specialize a generic method when saving it as a value:

    Manuscript
    import panic from "@std/faults.ms"

import List from "@std/collections.ms"

fn label(value: Int) -> String:
    return "item {value}"

test "receiver methods compose":
    let labels = [1, 2].map(transform: label)
    if not (labels.join(separator: ", ") == "item 1, item 2"):
        return panic(message: "check failed")
    let convert = [3, 4].map[String]
    if not (convert(transform: label) == ["item 3", "item 4"]):
        return panic(message: "check failed")

    Generic operations in these pinned native declarations do not add generic operation syntax to application-defined interfaces or implementations.

    Map and Set#

    Import Map / Set when naming or constructing them. Keys and set elements satisfy Hashable. Enumeration returns immutable lists in insertion order. Collection equality is independent of insertion order.

    JavaScript surfaceManuscript equivalentContract
    Map.size, get, has, set, deletelength, get, contains, with_entry, withoutExisting immutable receiver methods; missing lookup is Optional
    Map.clear, keys, values, entries, forEachclear, keys, values, entries, for_eachEntries are MapEntry(key:, value:); callback is fn(key: K, value: V) -> Unit
    Map.getOrInsertwith_default(key:, value:) followed by get(key:)Returns the updated map; an existing value is preserved
    Map.getOrInsertComputedwith_default_from(key:, create:) followed by get(key:)Callback receives key: and runs exactly once if absent
    new Map(entries), Object.fromEntriesimported map_from_entries(entries:)Duplicate keys keep first insertion position and use last value
    Map/object mergingmap.merge(other:)Right values replace matching entries in place; new keys append
    Set.size, has, add, deletelength, contains, with_value, withoutExisting immutable receiver methods
    Set.clear, values, keys, entries, forEachclear, values, values, entries, for_eachSet keys and values share one spelling; entries contain [value, value]
    union, intersection, difference, symmetricDifferenceunion(right:), intersection(right:), difference(right:), symmetric_difference(right:)New sets; left traversal order, then right-only values where applicable
    isSubsetOf, isSupersetOf, isDisjointFromis_subset_of(right:), is_superset_of(right:), is_disjoint_from(right:)Boolean relations; arguments are typed sets

    Use Map[String, T] for a dynamic string-keyed object. Statically declared records retain named fields and nominal identities. Prototype lookup, property descriptors, dynamic record reflection, WeakMap, WeakSet, and finalization registries have no corresponding data API.

    String#

    String methods need no additional import. The same algorithms are available as individually imported @std/string.ms functions. Strings are valid UTF-8; indexes and lengths below count Unicode scalars, not JavaScript UTF-16 code units or user-perceived graphemes.

    JavaScript surfaceManuscript equivalentContract
    length, at, charAt, charCodeAt, codePointAtscalar_length(), at(index:), scalar_at(index:)Scalar text / scalar integer in Optional; negative indexes count from end
    includes, startsWith, endsWithcontains(text:), starts_with(prefix:), ends_with(suffix:)Literal substring operations
    indexOf, lastIndexOfindex_of(value:), last_index_of(value:)Scalar index in Optional; empty search finds start / end
    slice, substringslice(start:, end:), substring(start:, end:)Slice clamps relative bounds; substring clamps nonnegative bounds and swaps reversed endpoints
    Strict scalar extractionslice_scalars(start:, end:)Existing Result returning OutOfRange for invalid bounds
    splitsplit(separator:, max_parts:)Positive maximum; final part retains the remainder; empty separator splits scalars
    concatconcat(values:), interpolationConcatenates text explicitly
    trim, trimStart, trimEndtrim(), trim_start(), trim_end()Unicode whitespace
    toLowerCase, toUpperCaselower(), upper()Go Unicode simple case mapping; not locale-sensitive full case expansion
    repeatrepeat(count:, max_bytes:)Existing bounded Result
    replacereplace(old:, new:, max_replacements:)Literal replacement; zero replacements preserves text; empty old inserts at scalar boundaries
    replaceAllreplace_all(old:, new:, max_bytes:)Literal replacement, including empty old; output limit checked before each append
    padStart, padEndpad_start(target_length:, padding:, max_bytes:), pad_end(...)Scalar length, complete scalar truncation of padding, bounded output; empty padding preserves text
    normalizenormalize(form:, max_bytes:)NFC, NFD, NFKC, NFKD; bounded output, Unicode stream-safe handling of long combining runs
    String.fromCodePointimported from_scalars(values:)Rejects surrogates and invalid scalar values
    match, matchAll, search, regexp replacementRegex.matches, find_all, replace; imported regex functionsRE2-style patterns; explicit match/output limits; captured-group/index records remain a gap
    UTF-8 conversionto_bytes(), Bytes.to_text()Invalid UTF-8 decoding yields none

    Locale collation/case mapping (localeCompare, locale case methods, Intl), grapheme segmentation, capture-rich regex results, and search start-position options remain gaps. Manuscript valid UTF-8 makes lone-surrogate repair (isWellFormed / toWellFormed) unnecessary. Legacy substr and HTML wrapper methods are intentionally omitted.
