      General-purpose packages#

      Standard library guide · Package coverage

      Find a package by the task you want to perform. Read common contracts for shared error and limit rules, and coverage to compare available functionality with Node.js or Go. The signature blocks are reference declarations, not complete programs.

      • Text, bytes, and collections — Work with text, bytes, encodings, collections, and regular expressions.
      • Numbers and mathematics — Use floating-point functions and arbitrary-precision integers.
      • Serialization and formats — Parse and write JSON, CSV, URLs, and escaped HTML text.
      • Paths and filesystem — Manipulate paths and use an explicit filesystem service.
      • Time and system information — Work with timestamps and query supplied clock or system services.
      • Cryptography and randomness — Hash, authenticate, encrypt, sign, and request random bytes.
      • Networking and TLS — Use destination policies, DNS, sockets, and verified TLS.
      • HTTP clients and streaming hosts — Use HTTP clients or request hosts with bounded bodies and cleanup.
      • WebSocket sessions — Send and receive messages within a WebSocket session lifetime.
      • Subprocesses and terminal I/O — Read terminal streams and run commands through explicit authority.
      • Compression and archives — Compress data and handle archive entries with explicit limits.
      • Logging, testing, and diagnostics

      Read a signature#

      For example, fn parse(text: String, limits: JsonLimits) -> Result[JsonValue, LibraryError] means:

      • Call the function with named text and limits arguments.
      • Success returns a JsonValue; an expected failure returns a LibraryError.
      • Import the function from the module listed above its signature. Import type names separately if your own annotations use them.

      A heading such as “FileSystem operations” lists methods on a supplied service. Importing its interface gives you the type; obtain the service value from the host or a function parameter. Read the behavior sections for limits, cleanup, and partial effects.
