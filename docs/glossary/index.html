    Plain-language glossary#

    Book index

    Use this page when the guide uses an unfamiliar term. Follow a link for the exact rules and examples.

    TermMeaning in this guide
    BindingA name attached to a value. let prevents reassignment; var allows a replacement value.
    ScopeThe part of a program where a name is visible. Nested blocks create nested scopes.
    ModuleOne .ms source file. It imports and exports individual declarations.
    RecordA value with named fields, such as a customer with a name and email.
    Nominal typeA type identified by its declaration. Two records with identical fields can still be different types.
    AlternativeA type with a fixed set of cases. A value is one case at a time and may carry that case’s data.
    Contract / interfaceA declared set of operations an implementation must provide.
    Generic parameterA placeholder for a type, such as T in List[T].
    BoundA requirement on a generic type, such as supporting equality or concurrent sharing.
    Intrinsic / preludeThe small set of types and compiler bounds available without imports.
    ResultEither a success value or an expected error value. Callers can handle or forward the error.
    OptionalEither a present value or none. Absence does not carry an error explanation.
    FaultA programming failure, such as a violated invariant. It ends the current operation after cleanup.
    Closure / captureA function value that keeps the surrounding values it uses. Captured bindings are snapshots.
    AliasAnother reference to the same object. Closing a resource affects every alias.
    Resource lifetimeHow long a file, connection, or other external resource remains open and usable.
    SharingValues may be passed between operations. Local mutable queues need explicit synchronization; sharing does not keep resources open.
    Capability / authorityA passed-in object that permits external operations, such as file or network access.
    EffectExternal behavior reachable from an operation, such as reading, writing, or calling a service.
    Operation / groupOne invocation started by a concurrency API / the invocations started by one parallel call.
    JoinWait until every started operation has finished, including its cleanup.
    Execution contextRuntime state carrying an operation’s cancellation signal and deadline. The runtime passes it internally.
    Cancellation checkpointA point where work checks whether it should stop and unwind.
    UnwindLeave active scopes and run their registered cleanup.
    Shielded cleanupCleanup that can run despite the cancellation or deadline that ended ordinary work.
    HostThe runtime entry point that runs a CLI application or handles HTTP requests.
    AdapterA declared bridge between Manuscript and foreign code, such as Go.
    Typed IRThe compiler’s internal program representation after names and types have been checked.
    LoweringTranslating checked Manuscript operations into generated Go while preserving their behavior.
    ConformanceTests and evidence that the implementation follows the language’s rules.
    NormativeDefines a required rule. Other explanations and examples must agree with it.
