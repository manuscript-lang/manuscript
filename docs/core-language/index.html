      Core language#

      Book index

      Learn to read and write Manuscript one step at a time. If you have not run a program yet, start with your first program .

      Suggested reading order#

      StepReadWhat you will be able to do
      1Language basicsRead a file, name values with let or var, and use numbers and text.
      2FunctionsDeclare inputs and outputs and call functions with named arguments.
      3Types and data modelingModel data with records, alternatives, optional values, and collections.
      4Control flowChoose a branch, repeat work, and handle each case of an alternative.
      5Errors and validationReturn expected errors, handle them, or forward them with try.

      You do not need to read every reference page before writing code. Return to grammar , operators , and type compatibility when you need an exact rule. Core conformance fixtures contain complete modules and their expected outcomes.
