# Bounded overlay-footprint correction to owner watcher

Review-only until root decision. Current candidate50d has a concrete blocker: an open A/link.ms (or A/alias.dir/dep.ms beneath A's manifest) can contribute text to B through canonical overlay admission. Deleting the lexical symlink can leave selected ownerA unchanged and reconstruct an event beneathA, while cachedB still owns the prior admitted text. Matching only selected lexical/canonical owner roots loses that historical physical footprint.

Proposed minimal metadata: one generation-local map actual ordinary URI→resolved physical filename, captured for ALL ordinary open snapshots before the first live compilation, including unrequested docs. Capture once alongside canShareOverlays, without stopping after the first divergent decoded filename; immutable standard docs have no footprint. Reuse eventCanonical only as conservative invalidation metadata, never overlay/import admission. Uncertain resolution records a global-fallback obligation. Ordinary didOpen/change/close reset this map with existing full invalidation. No Program or import-edge graph is added.

Before selective watch eviction, recompute current ordinary footprints and union: (1) all old/current physical filenames whose URI's mapping changed, and (2) prior physical filenames for every actual URI beneath a received lexical/physical event path (exact or ancestor). Feed those additional file footprints to existing whole-owner matching. Keep original event paths so lexical ownerA also invalidates. Retarget/deletion under an unchanged manifest therefore refreshes B and A; unrelated C keeps its identity. If either old/current resolution is uncertain or a live generation lacks required footprint metadata, use full invalidation/publication. Update retained metadata only after a complete decision; failed validation never means empty overlays.

Regression matrix: only B checked (A's ordinary doc never gets URIcache); A file symlink→B/dep with divergent unsaved text; A nested directory symlink→B/subdir with manifestabovealias; delete and retarget lexical route; actual physical old/new event; encoded variants unchanged; ordinary no-alias/immutable docs; unaffected C cached/index/lint/publication. Fresh B transitions stale type failure→disk success after alias deletion. Deliberately dropping the old-footprint expansion must fail these tests.

The map adds O(open docs) small path metadata and one conservative physical resolution per ordinary URI per generation. It must be measured on ordinary didChange as well as watch workloads, since the previous50d balanced pair does not include this additional cost. Do not claim50d timing for a revised candidate. Existing no-alias compile/publication counts must remain identical; owner-event savings need final-source remeasurement. Global fallback for all generations containing aliased/unknown overlays is a smaller alternative but would sacrifice selective invalidation for safe directory aliases; root can prefer that tradeoff rather than expand scope.
