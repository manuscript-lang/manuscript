# Manuscript agent bench, 2026-10-22: compact cheat sheet

claude-code + claude-haiku-5-5, ms small challenges (c03-c44), one trial each, `ms` built from main after the compact cheat sheet (#959, #964). Source size is LLM tokens (tiktoken `o200k_base`). Raw runs: `trials-2026-10-22.jsonl`; sources in `sources/`.

| | 10-21 | 10-22 |
|---|---:|---:|
| pass | 9/10 | 10/10 |
| first build ok | 2/10 | 1/10 |
| source tokens, same 9 challenges | 11,435 | 11,272 (-1.4%) |
| ms / ts source tokens (TS from 10-21) | 1.30x | 1.28x |

What changed in the sources: list indexing `xs[i]` replaced `.get(i)` (247 vs 27 uses), `read_lines` appears in all programs, and `flush()` is gone. Agents still barely use one-line `if c: return x` (3 uses) and write typed closures (2 typed, 0 untyped), so the lines-per-program gap is unchanged. Hand-written compact sources for c03 and c16 total 1,007 tokens against 948 for TS, so the language already allows the smaller programs; the cheat sheet alone does not make agents write them.
