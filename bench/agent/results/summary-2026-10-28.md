## Comparison with other languages

Other languages are from the 2026-10-18 baseline (`leaderboard-2026-10-18.md`, same harness and model, one trial per challenge, not rerun); Manuscript is shown for both dates. Tokens, turns, wall time and cost average over passing trials with recorded usage (the three timed-out passes have none, so the 10-28 means cover 14 of 17). Agent tokens are input including cache reads plus output; solution size is lexical tokens as in the leaderboard.

Manuscript closed most of the gap in pass rate (65% to 85%, against 90-95%), solution size (now about the size of TypeScript, 3490 vs 3451) and cost, and halved agent tokens, but it still uses about 3-4x the tokens, 2.5-3x the turns and 1.1x the wall time of the other languages, and it is the only one that mostly fails its first build. The 10-28 run used a newer compiler, cheat sheet and `ms search_symbol`, so the change is not attributable to any single one. The other languages' numbers are two weeks older and single-trial.
