# The performance suite: one line per group, `name | kind | command | results`. This file is the
# index `ms run bench/tools/perf.ms` reads (`make perf-list`, `make perf GROUP=<name>`).
#   kind     time = wall time or ns per operation, count = instruction or allocation counts,
#            probe = a dated protocol read from its page (no single command)
#   command  run from the repository root without a shell; `ms` is $MS (default
#            .artifacts/build/release/src/cli/ms) and {n} is the sample count (default 5)
#   results  the page that holds the latest dated numbers, relative to bench/perf/ (a leading
#            `../` reaches bench/). Add a dated section rather than editing old numbers.
# Comparisons against C use checked C (overflow and bounds checks on). A group never moves
# out of this file without its results page and its README entry moving with it.
