# Avoid the second scan after an ordinary JSON syntax error

Baseline `4be5d6d8c2defb9fc6eb75c8c43bd68a5314d192`, Linux x86-64, Rust 1.99.1, LLVM 23.1.1, `Release` with observed `opt -passes=default<O3>` and `llc -O3`. The only native source delta is the [retained patch](evidence-2026-10-29/fix.patch). [Environment](evidence-2026-10-29/environment.json), [identities](evidence-2026-10-29/identities.json), [all samples](evidence-2026-10-29/samples.jsonl), and [instruction counts](evidence-2026-10-29/callgrind.json) are retained.

A leading `]` already determines `InvalidData`. Previously the failure classifier still searched all remaining bytes for backslashes and potentially scanned all Unicode escapes before returning that same error. The change returns immediately when no parser limit was hit. The Unicode scan still runs when needed to preserve Unicode-error precedence over a parser limit.

Nine before/after pairs per case follow a discarded warm-up pair. Every process exit, case identity, round count, positive timer and checksum is checked. Each iteration verifies the exact expected error, or compares the complete valid string payload. Input construction, compilation, process launch and output are outside the clocks. Runtime-only process CPU measurements supplement wall time; they do not remove frequency/cache variability. No compilation or other substantial task CPU work ran alongside the trials.

Times below are wall nanoseconds per parse, shown as median [min–max]. `plain` and `escaped` use an immediately invalid prefix followed by that many plain bytes or backslashes; `typed-*` requests a String through the document decoder. The untyped malformed-prefix path becomes independent of suffix size. Typed parsing still copies the document: its one-megabyte escaped-suffix median falls from 1.689 ms to 100.6 µs, while the untyped median falls from 1.397 ms to 103 ns. The shared VM is noisy, especially for tiny cases; no valid-input speedup or universal common-case throughput claim is made.

Collected native instruction counts make the work removal explicit: for a 65,536-byte escaped suffix, untyped parsing falls from 787,488 to 975 instructions/call and typed parsing from 855,033 to 68,520. All six valid control cases have identical before/after instruction counts. The benchmark is diagnostic, not a CI timing threshold.
