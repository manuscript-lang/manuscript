# Benchmark refresh, 2026-11-05

Fresh runs on current main for the public docs. Compare only against numbers from the same machine.

- Revision: `9832978d` (main, 2026-11-05), `ms` Release build (`make build`, LLVM backend).
- Machine: Intel Xeon @ 2.10GHz, 4 vCPUs, 15 GB RAM, Linux 6.18 (shared cloud VM). Go 1.24.7, rustc 1.99.1, gcc, LLVM 18.
- The kernels and workloads sources no longer compiled under the one-owner memory model (`var x = list.get(i)` borrows); this change adds `.clone()` in `bench/perf/kernels/ms/src/main.ms` and the c36 reference solution so they build. Behavior and checksums are unchanged.
- Not rerun: the agent benchmark (`bench/agent`) needs model access, which this environment lacks. Its latest results stay in `bench/agent/results/`.

## Compile time (single run, cold)

Command: `ms run bench/tools/compile_time.ms` (40 packages x 25 files x 10 functions, about 122k lines of Manuscript; see [`bench/compile-time/README.md`](../compile-time/README.md)).

| step | 2026-10-31 | 2026-11-05 |
|---|---:|---:|
| go build (cold) | 10.2 s | 9.04 s |
| ms check | 1.8 s | 2.18 s |
| ms emit | 2.9 s | 2.16 s |
| ms build Debug (Cranelift) | 10.5 s | 5.42 s |
| ms build Cranelift release | 12.3 s | 7.19 s |
| ms build Release (LLVM) | 293 s | 43.55 s |

Release builds are 6.7x faster than on 2026-10-31 and Debug builds 1.9x faster; Debug and Cranelift release beat Go's cold build on this workload, and LLVM Release is 4.8x Go's. Go's touched-one-file rebuild (0.23 s) was not remeasured.
