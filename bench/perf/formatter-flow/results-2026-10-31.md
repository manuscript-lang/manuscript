# 2026-10-31: bounded formatter flow and suffix scans

Baseline: `26d586480a0aa786035d3def7bfe47651c96e297`, including formatter correctness #2049. Candidate changes only `crates/ms-syntax/src/format.rs`, plus focused fixtures, benchmark evidence and a wiki lesson. This is a Rust tooling implementation comparison, not a generated-language Rust parity result.

Host: Linux 6.18.57 x86_64, AMD EPYC 9V45, five allowed CPUs, about 17 GiB RAM. Every measured child was pinned to CPU 0. Official pinned Rust/Cargo 1.99.1 (`58cf8f9c3 2026-10-13`), identical release opt-level 3, debug info and panic abort, default host target, no LTO/custom CPU flags. No simultaneous builds/tests or other intentional CPU-intensive tasks ran during timing; the host is not claimed exclusive.

All **1,180 invocations** (59 workloads × ten samples × two binaries) completed, checked format idempotence and matched full-output fingerprints and source/output sizes. Each process performs two untimed formatting calls (original source, then its output), followed by the calibrated measurement. Generation and correctness checks are outside the timer; complete formatting and full-output fingerprinting are inside it. See the [protocol](README.md) and [every raw observation](results-2026-10-31.csv).

## Cause and result

Leading flow dots repeatedly searched the current item prefix, while every empty call measured an overlapping suffix. The combination approached cubic growth on implicit flows. Track preceding significant-token/pipe facts per item instead. For suffix lookahead, retain the exact renderer for short tails but stop when a conservative lower bound already exceeds WIDTH. Each nonempty emitted outer token contributes at least one character; returning WIDTH+1 then preserves the only consumer's overflow decision. Newline/comment/clause/nonempty-group boundaries and parameter overrides remain unchanged.

On the final full matrix, a valid 2,048-step implicit flow falls from **3.162 s to 4.172 ms** (about 758×); the explicit-pipe control falls from **59.836 ms to 4.636 ms**. At 512 steps, implicit flow is 53.364 → 1.031 ms. The initial prefix-only experiment reached about 46.6 ms at 2,048 steps, exposing the remaining suffix cost; it was not presented as the final fix.

These improvements preserve the existing formatter contract, including correctness #2049's flow semantics. The new LF/CRLF golden covers comments, nested groups, item commas, explicit pipes and try. It was captured with unmodified formatter code; an independent reviewer copied the new test/fixtures into untouched baseline production at `26d586480` and ran it: one passed. The matrix separately covers compact/expanded cases, 28–32-step cutoff neighbors, nonempty groups, clause stops, Unicode and ordinary calls/lists.

## Costs and noise

All recorded samples are retained. Ten balanced AB/BA fresh-process observations limit directional drift but do not prove that small shifts are causal or absent. No median is more than 3% slower; the largest increase is **+2.04% for eight-step member chains**. Ordinary 1,000-function formatting is **6.185 → 6.260 ms (+1.20%)**. These costs remain visible. Selected sample ranges below show the distribution; raw rows permit other analyses. No universal improvement or regression-free threshold is claimed.

Passed: 179 affected tests/doc tests via `cargo test --locked -p ms-syntax -p ms-lsp -p ms-tooling`; affected-crate clippy with warnings denied; workspace and standalone Rust formatting; repository invariants; standalone harness clippy and comparator syntax. Independent review accepted both invariants before implementation and checked final source, all rows/order/fingerprints/medians and baseline oracle provenance with no remaining correctness finding. No GitHub approval was submitted. Normal required CI and final combined-main replay remain required. Full local native/workspace/conformance execution remains outside the campaign's denied backend, ownership/cleanup, Windows and HTTP/network investigations.
