## Result and limits

Repeated source-prefix scans caused quadratic literal/whitespace hover and
reference rendering. Resolve an ordinary cursor once and compare exact token
byte ranges; invalid/mismatched snapshots retain the old UTF-16 comparison.
Batch reference locations by adjacent file, using one module list and a line
index only through the final needed offset. The prefix bound prevents a single
early reference from scanning an unrelated 1 MB trailing comment.

At 1,000 functions, literal hover falls from about 41.8 ms to 0.109 ms; at 4,000,
668 ms to 0.437 ms. A 1,000-use reference query including JSON rendering falls
from 8.13 ms to 0.974 ms; 4,000 uses fall from 120.5 ms to 3.36 ms. These are
workload-specific application improvements, not universal ratios.

Unchanged controls have median ratios from approximately 0.926 to 1.039,
including slow observations that are retained. The 1,000-function indexed-name
control has overlapping ranges (18.94–21.41 μs before, 18.95–45.44 μs after),
and formatting has overlapping ranges (6.95–7.67 ms before, 7.20–10.23 ms after).
Small control shifts and shared-VM noise remain; this is not a claim that every
path improves or a CI threshold. Final combined-main replay is required after
the concurrent correctness PRs merge.

An earlier full-line-index hover candidate was rejected after an indexed-name
control repeatedly rose about 10–11%. A standard-string newline-search candidate
also failed controls and was rejected. Their local artifacts remain in the lane
checkpoint; neither implementation is retained. A reference-only intermediate
pass and the weaker length-only discovery pass were retained separately locally;
the table here uses the final combined patch and full fingerprints exclusively.

Malformed/mismatched snapshots have correctness tests, not throughput claims.
Multi-file replacement/order is tested but not a large workspace performance
baseline. Completion still includes checking work; this patch makes no claim to
remove it. No backend, ownership/lifetime, Windows, Debug JSON, or HTTP/network
investigation was performed. The lane is not declared exhaustively clean while
fresh merged-main and workspace controls remain pending.
